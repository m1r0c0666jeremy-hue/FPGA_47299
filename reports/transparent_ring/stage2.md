# 阶段二：网格边缘和候选质量

所有输入为构造像素/掩码，实物待验。

| 对照 | 基线 | 新默认实现 |
|---|---|---|
| 3×16、16×3 全部 16×16 相位，共 512 色带 | 432/512 达到 48 支持像素 | 512/512，面积和真实坐标重心逐项正确 |
| 远隔核心之间三格弱链 | 不计边缘 | 补计直接边缘、不沿弱格继续扩展，两个区域不合并 |
| 四个图像边缘、空心环、狭长带 | 原回归保留 | 原掩码保持，区域保留 |
| 大量弱双像素碎片与强局部支持细色带 | 主要按面积保留 | 支持率优先，细色带进入第一候选 |
| 严格支持数≥4对照 | 无此门槛 | 删除了构造的碎裂打印区域，因此正式默认 STRICT_SUPPORT=0 |

filter4 的 ha/hb 宽度扩展为 8：低四位是原显示掩码，高四位是至少两个同色邻居的统计掩码。采集全部接收；显示只使用低四位。独立逐像素参考通过两连续完整帧，含行尾、底行、新帧重叠和所有边缘。

每格追加两色 9 位局部支持计数。候选[89:83]为支持率百分比，[91:90]为比例档位；比例不是颜色识别置信度。排序保持历史邻近/中央优先，其次支持率档位，再比较封顶面积。不硬性拒绝低填充、空心和狭长区域。

flags 明确区分核心、边缘和访问状态；边缘只计入一次且不扩展。固定扫描/方向下，共享边缘归属首个核心；首个区域最后不合格时不会转交。这一偏置已由 shared_fringe 和 rejected_first_owner 测试复核，并未宣称唯一正确归属。

固定容量队列仍为每色最多 3600 项。保守上界：15416 预处理 + 14400 扫描 + 144000 节点处理 + 7200 区域结束 + 864 最终除法 + 4 控制 = 181884 拍，低于 212000 硬截止。压力测试实际 173893 拍；双银行同时采集/处理及四候选回归通过。

区域位移测试直接初始化真实像素统计，单独验证图处理；实际采集统计、滤波、参数帧尾关联由 stable_units 和 stable_adversarial 的完整输入链回归覆盖。
