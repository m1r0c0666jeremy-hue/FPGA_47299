# 阶段一：实际DDR握手、银行提交与行预取

基线：2f79847；本阶段尚未完成TD资源/时序检查，不产生可交付bit。

## 修改

- 新增项目自有FIFO命令适配器及DDR包装层。AR、AW、W分别保持到接受，地址/数据可分拍完成，支持完成同拍装载下一条命令。厂家原模块和掩码语义保留。
- 银行完成改为统计实际已完成地址与数据握手的写操作。每个银行独立计数，上一帧队列尾部跨越下一银行开始时仍可正确完成；乱序地址、超长帧和银行复用作废。
- 增加384位预取寄存器，隐藏各组之间四拍装载。两个分类器及三行缓存保持。
- 新入口target_color_regions_refined.al，原未提交工程和历史交付均由保护清单核验。

## 软件对照

| 输入 | 修改前 | 修改后 |
|---|---|---|
| AWREADY=1、ARREADY=0后再释放 | 读命令丢失，实际接受0条 | 实际接受1条且地址正确 |
| 实际厂家FIFO、独立PAXI就绪与队列压力 | 原测试未覆盖 | 1800命令：1200写、600读，地址/数据稳定，数量、顺序及返回正确 |
| 银行切换后上一帧尾写才提交 | 当前银行式计数不能正确处理 | 原银行完成，新银行未完成时不发布；乱序/复用保护通过 |
| 0°同源行RGB与掩码 | 每行装载/分类960拍 | 644拍，检查5120RGB及2560有效掩码像素 |
| 180°同源行RGB与掩码 | 每行装载/分类960拍 | 644拍，检查5120RGB及2560有效掩码像素 |

首次仿真发现测试把未发布的上方预取边缘掩码纳入检查；修正测试范围为实际视窗有效行。失败日志和修正后日志均保留，旧回归日志未覆盖。

运行入口：scripts/test_refined_ddr.py、scripts/test_refined_prefetch.py。逐次日志及源文件哈希位于reports/refined/regression。

## 边界

控制器在仿真中由独立握手模型驱动，真实命令FIFO和项目包装层参与测试；此结果不等于完整厂家DDR物理模型或实物黑闪已经解决。后续还需超时/恢复、完整帧、全视频链和TD检查。
