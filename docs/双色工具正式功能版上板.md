# 双色工具正式功能版：上板与校准

本版实现材料校准、独立颜色区域、中央选取一件工具、尖端估算和放大窗口跟随。工程入口仍为 `td_project/target_color_regions.al`，当前仓库为 `D:/aaa_FPGA/color-regions-env-issues`，分支为 `docs/color-regions-env-issues`。最终下载文件和 SHA256 见 `reports/stable_regions_delivery.json`；旧 `build/target_color_regions/` 中的 bit 属于历史颜色区域版。

软件和 FPGA 编译结果见 `reports/双色工具正式功能版验证报告.md`。新版本的实物指标必须按下方记录，上述验证不能代替实物成功率。

## 1. 按键和页面

开关上为 0、下为 1。页面按 `{SW1,SW2}` 排列：

| SW1/SW2 | 页面 |
|---|---|
| 上上 00 | 原图 |
| 上下 01 | 颜色高亮 |
| 下上 10 | 灰度 |
| 下下 11 | 颜色二值 |

- SW3 上：红 A／蓝 B；下：黄 A／紫 B。A 必须靠近尖端，B 在后方。
- KEY1：复位，回待命、1 倍、标注开启，清除两组校准。
- KEY3 短按松手：启停选取和跟随。满一秒长按：标注显隐，检测继续运行，底栏保留。
- SW4 上：KEY2 调暗、KEY4 减小倍率；SW4 下：KEY2 调亮、KEY4 增大倍率。倍率为 1、2、4 倍，到端点保持，长按可重复。
- 调亮度会暂停跟随，两组校准都需更新；上一套完整增益和模型仍保留，标为不可用于跟随。当前配色完成校准后才能重新选取；另一组仍提示重新校准。
- 校准保存在寄存器中。启停、页面和倍率切换保留；复位、断电清除。

## 2. 推荐校准顺序

先选定照明、相机亮度和配色，再进行校准。对实体色环、平放色环、打印标记分别学习其实际材料；同一组只保存最后一次完整成功的材料参数。

1. 待命时，同时按住 KEY2＋KEY4 一秒。组合期间不调整亮度或倍率。
2. 底栏提示“白纸按 KEY3”。画面暂时固定为中央 1 倍原图；中央绿框对应源图 16×16 像素，源坐标 x=632～647、y=352～367。用均匀白纸完全覆盖绿框，短按 KEY3，保持到提示下一步。
3. 提示“A 色按 KEY3”时，把红色或黄色材料放进绿框，短按 KEY3，保持到下一步。细环允许绿框内有中性孔洞，但每帧至少 16 个有效材料像素、八帧合计至少 256 个；建议让色带穿过绿框。
4. 提示“B 色按 KEY3”时，采样蓝色或紫色材料。成功后自动回待命，并恢复所选页面和倍率。短按 KEY3 开始中央选取。
5. 另一配色需要其独立校准。切配色会清除当前选取历史，保留该组已完成的材料参数。

每步积累八个**完整采集帧**，随后串行计算。出现“采样处理中”时保持材料；处理结束后再操作。校准中 KEY2 取消，切配色也取消。失败、取消均保留上一套完整成功参数，不会发布半套 A/B 模型。颜色模型只在新帧开始时切换。

材料采样宜使用中性白纸或黑底。彩色 PCB 背景会计入混色比例，细色带不能占满合格彩色样本时，应重新摆放或让材料在绿框中占更多面积。需要调整相机亮度时先取消校准，回待命调整，再重新从白纸开始。切换至另一组待更新参数时，先用 KEY3 停止搜索再进入校准。

默认白平衡为单位增益，不随场景持续变化。白纸校准计算红、蓝相对于绿的固定增益，范围 0.5～2 倍。白纸过暗、过曝或增益需求超范围均拒绝。颜色阶段在白平衡后逐像素分析，排除中性背景；主色相簇须占所有合格非中性色样本至少 60%。模型使用 5～95 百分位，两侧各扩展 8°；上界使用不包含该端点的整数区间，额外加一度包含原 95 百分位。

### 失败代码

| 底栏 | 含义与处理 |
|---|---|
| E1 | 采样帧长度或窗口组数异常，稳定图像后重新确认该步骤 |
| E2 | 白纸太暗、太亮或不均匀，调整摆放和照明 |
| E3 | 所需白平衡增益超出 0.5～2 倍，检查光源或白纸 |
| E4 | 材料像素不足、某帧不足 16 个，或混色导致主簇不足 60%，重新摆放 |
| E5 | A/B 模型重叠，重新采样两种材料 |
| 请重新校准 | 相机亮度已经改变；先校准当前配色 |

## 3. 中央选取和跟随

把同一工具的两色标记都放在中央 640×360 引导框中，短按 KEY3。标记中心距离必须为 16～600 个源像素；先选择双色中点最接近画面中心的一对，连续三个完整帧符合位置、间距、方向和面积连续性才确认。

初次选取建议使用 1 倍，让两色和完整引导区都可见；确认后再放大。中央优先按中点横纵偏差之和排序。

确认后移动工具。尖端为 `T=(3A−B)/2`，横纵坐标分别计算，半像素按整体结果四舍五入、恰好半格向离零方向舍入。工具实际应满足标记距离 L 与 A 至尖端距离 D 的 `D/L=0.5`；不满足该几何比例会有系统误差。

位置采用 1/2 权重平滑；窗口每个新结果最多移动 24 源像素，4 源像素以内不移动，并限制在图像内。窗口冻结不会延长旧图像或旧结果的有效期。1 倍页面包含 624 行图像与 96 行底栏，因此上下会有源图裁切；2、4 倍可随尖端移动到边缘。

缺少任一颜色时立即隐藏尖端、冻结窗口，另一颜色框可继续显示。保留工具身份最多 15 个新采集帧；附近同一工具重新连续三帧匹配后恢复。超时显示“中央重选”，不会自动改选其他物体；把工具放回中央，短按停下，再短按重新选取。

## 4. 材料和间距条件

- 合格标记外框至少约 16×16 源像素、至少 48 个支持像素。3 像素宽、16 像素长的色带是软件检查的最小样例；实际透视、模糊会减小有效面积。
- 去孤立处理保留中心命中且八邻域中至少还有一个同色点的像素。原图 RGB 不做模糊；不要求圆形、空心或较高填充率。
- 同色物体若需要独立分开，间距至少 32 源像素；真正接触的同色部分会属于同一区域。
- 框按 16×16 网格外沿显示，单侧额外边距最多约 15 源像素；重心使用真实像素坐标和，并非网格中心。
- 每色保留四个候选。搜索偏向中央，跟踪偏向原目标附近；同色对象数量更多时，不能保证全部进入候选。标记几何非常相似且交叉遮挡时，图像颜色本身无法提供绝对物体身份。

## 5. 实物验收记录

下载前核对交付清单 SHA256。记录板卡、相机、焦距、相机增益、照明和实际 bit 哈希，拍摄连续视频。当前新 bit 未由本次工作下载至板卡。

`reports/stable_regions_hardware_trials.csv` 预留三种材料×三种背景×两种配色×十次，共 180 行；空白结果表示待验。请填写成功/失败、首次锁定采集帧数和失败原因。

`reports/stable_regions_hardware_metrics.csv` 记录各组合的静止十秒尖端/窗口峰峰抖动、平面标记误差、无遮挡恢复、无工具六十秒误尖端，以及实测 bit 哈希。验收标准：

- 每组合十次中央选取至少九次成功，正常目标六个采集帧内首次锁定。
- 静止十秒，尖端和窗口峰峰抖动分别不超过四源像素。
- 平面标记满足 K=0.5 时，尖端误差不超过八源像素。
- 无工具连续六十秒不显示有效尖端；遮挡时停窗，恢复保持同一工具。

失败时同时记录原图、二值页与底栏：区分“材料未命中”“命中但区域条件不足”“配对确认失败”“图像/结果未就绪”。不要把扩大所有阈值当作统一修复。
