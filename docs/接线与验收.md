# 接线与验收（ImagePreprocess）

更新：2026-10-03。基础引脚对照已完成，实物反馈队友原版本成功出图。这里保留现行映射与本轮验收，不再重复旧引脚冲突待办；历史证据见 `reports/队友版本同步与复核.md` 和Git历史。

## 当前用户引脚

依据《新HX1P35A开发板手册-HDL版2604》及编译后的IO报告。

| 信号 | FPGA球位 | 功能 |
|---|---|---|
| I_sys_clk | C4 | 50MHz参考 |
| I_rst_n | D5 | KEY1，低有效复位 |
| I_button[0]/[1] | A9/B9 | KEY2/KEY3，原曝光调节 |
| I_switch[1]/[0] | A4/B4 | SW1/SW2；上1下0；SW1为模式高位 |
| 摄像头SCL/SDA/参考/RST | K3/J3/L3/L2 | 配套SC500接口 |
| HDMI D0/D1/D2/CLK正端 | G16/F17/H14/C17 | 负端分别H16/E18/H13/D18 |
| O_screen_pwm | D10 | 名称沿用，实际为LED1心跳，不是屏幕供电 |

项目用户约束为 `td_project/imagepreprocess_10_3.adc`，DDR/MIPI专用资源仍依厂家IP配置与约束。表中球位不是连接器针序。

## 新bit验收顺序（待实测）

| 步骤 | 操作 | 记录/通过条件 |
|---|---|---|
| 1 | SW1/SW2均下，00原图 | 摄像头画面、RGB色卡、边界；显示器菜单实际输入模式 |
| 2 | SW1下SW2上，01边缘 | 细线/黑白边缘；前两行/列黑边符合约定；坐标偏移见算法说明 |
| 3 | SW1上SW2下，10灰度 | 红绿蓝与灰阶；与灰度公式对应 |
| 4 | 两者均上，11二值化 | 黑白输出；灰度≥128为白；评估当前曝光下适用性 |
| 5 | 反复拨动、不同顺序拨动 | 稳定后在帧边界改变，无同帧混用；长时间中间组合可显示中间模式 |
| 6 | 多次启动/复位、运动/遮挡 | 记录花屏、停流、撕裂与恢复结果，旧缺陷仍可能触发 |
| 7 | 四模式运行并反复切换，累计至少30分钟 | 时长、异常次数、复位次数、环境和画面证据 |
| 8 | 分别测量 | 摄像头fps、HDMI刷新Hz、端到端延迟；不混成一个数值 |

出现显示问题时，可单独将DEBUG_MODE改为1彩条或3状态条后重新编译，开关先置00；状态条仅表示历史事件，不证明持续健康。保留75MHz、理论60.606Hz；队友的基本出图反馈不替代每个显示器组合的裁边、刷新率和长期稳定性验收。
