# 路线录制与回放

切换到 11，在真实尖端有效时短按 KEY2 开始录制，再按 KEY2 结束。单条路线最长约 30 秒，每秒最多记录 20 个位置，保留移动节奏与停顿。收到第一个有效新样本后才替换旧路线；无效启动保留旧路线。

短按 KEY3 回放，KEY4 停止。回放使用已记录的位置来驱动准心、放大窗口和区域判断，工具可以拿开。回放点不表示此时正在跟踪实物。位置按时间戳每 50 毫秒选取，放大后可能看到阶梯移动；不绘制完整路线折线。

有已保存区域且没有草稿时，回放同时检查顺序；没有区域或留有草稿时只回放位置，底栏提示顺序判断未启用。FAIL 时停在错误点并报警，DONE 后保持终点。长按 KEY4 清路线，复位和断电也会清除，路线不写入 Flash。

完整按键、校准和故障信息见 [本分支使用手册](USER_GUIDE.md)，下载文件见 [编译与下载](BUILD.md)。
