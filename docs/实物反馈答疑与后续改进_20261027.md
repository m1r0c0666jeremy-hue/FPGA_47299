# 实物反馈答疑与后续改进

日期：2026-10-27。对象：Jeremy反馈的三张实物照片及00／01／10／11档操作问题。

**结论：亮度按键的控制数值确实改变了，但照片和旧软件验证都不能证明相机实际执行了增益；01的两个删除键只在一份草稿点时表现相同；当前没有靠近／远离／静止分析；11的STOP FIRST是取消回放暂停后留下的操作提示。** 本轮补充亮度写后读回、简化01按键、共享K调节及播放提示。新功能处于实现与验证中，不能用旧候选的124项软件或旧布线结果证明本轮已通过。

## 1. 照片中的亮度值为什么变了，画面看起来没变？

三张照片可读到的底栏依次是`BRT016 1/7`、`BRT032 2/7`和`BRT048 3/7`。它们说明控制程序切换到了16、32、48三个设定档位；`1/7`表示七个档位中的第一个。完整档位是16、32、48、64、80、90、105。`BRT105`也是这套控制数值，不代表105%亮度。

此前显示的BRT值，表示软件已完成相机配置写入流程后保存的数值，**不是从画面测量出来的亮度，也不是传感器寄存器的实际读回值**。旧相机测试检查了写入应答，但测试相机没有真正解码所有写入值再读回，因此“OSD变化”不能单独证明硬件增益变化。

相似的照片值得继续检查，但暂时不能确定实物根因。手机自动曝光、环境光变化、拍摄屏幕产生的反光，以及画面本身接近过曝，都会影响肉眼对比。不能直接归因于示教模块，或因文字已变化便判定正常。

本轮采用以下确认方法：

- 相机初始化后读芯片身份：`0x3107=0xEE`、`0x3108=0x27`。
- 每次亮度步骤完成六个配置写入后，再逐项读回。检查`0x3E03`低四位为`0x0B`，`0x3E00=0x00`、`0x3E01=0x7C`、`0x3E02`高四位为`0x60`，以及`0x3E08/0x3E09`与本次增益查表的两个字节相符。
- 全部匹配且请求身份未变后，才发布已应用数值和完成应答；实际相机恢复原有三帧完整图像确认。请求目标和已应用数值在忙时分别显示。
- 芯片身份不符、读写无应答、超时或读回不符要显示故障，不能只把底栏改成目标数值。

底栏故障名称：`CAM NACK`为相机无应答，`CAM TIMEOUT`为通信超时，`VIDEO LOST`为图像中断，`CFG RD FAIL`为配置读回不符，`CAM ID FAIL`为芯片身份不符。终止故障在所有模式底栏显示，即使标注隐藏、保留校准文字或处于回放也能查明原因。

这些检查能证明配置链路是否按预期执行；不能代替实物画质确认。Jeremy最终需在固定相机、固定光照和同一非饱和目标下比较16与105两端。若寄存器一致但图像仍无差别，再依据实测检查传感器模式、光学和曝光条件。

## 2. 01档KEY3和KEY4是否重复？

旧版KEY3短按清空全部未保存草稿；KEY4短按只撤销最后一个点，没有草稿时才逆序删除已保存矩形。

因此只有一个草稿点时，两键都使点数从1变0；若两点因太小、重叠或相接而保存失败，KEY3会从2点清到0点，KEY4则从2点退到1点，便于重新选择第二角。两者并非在所有情况下相同。

本轮已确定取消**01档KEY3短按清草稿**，仅保留KEY4撤点／删区。要清两点草稿，KEY4按两次即可。KEY3长按约一秒仍负责跟踪开关。这样操作更统一；释放的是01档的短按用途。

## 3. 10档的靠近、远离和停留在哪里？

当前没有启用`APPROACH`靠近、`AWAY`远离、`STILL`静止分析。这是上一轮为缓解资源与布线压力已批准的精简内容，本轮继续保持。

10档仍有区域顺序、当前区域和**区内停留计时**。例如`NEXT B`表示下一目标B，`IN A`表示当前确认在A，`T002.5s`表示连续处于当前区域约2.5秒。即使准心在区域内部移动，T仍会增加；它不能解释为“工具静止了2.5秒”。进入最后目标区后即判PASS，终态会冻结计时，所以最后一区的T可能很小。

因此没有看到靠近／远离不是观察遗漏；需要查看的是底部两行OSD中的NEXT、IN、T、PASS／FAIL、暂停和静音信息。

## 4. 11播放中KEY3提示STOP FIRST有什么用？

示教回放已精简为播放、停止、从头重播。KEY3在待机、DONE或FAIL时启动／重播；播放中再次按KEY3不会暂停，也不会跳回开头。`STOP FIRST`表示若要从头播放，应先按KEY4停止，再按KEY3。

旧提示容易误导：播放中的提示仍写`K3 PLAY`，误按后的STOP FIRST还可能一直保留到DONE。本轮按已确定方案改为：播放中只显示`K4 STOP`，KEY3短按直接忽略，不显示STOP FIRST，也不增加临时提示。待机／DONE／FAIL时再显示KEY3播放／重播。录制期间不允许的操作仍按原规则提示。此改动不恢复暂停功能。

## 5. 新增K调节怎样改善定位？

双色法把后标记B、前标记A和尖端T视为同一直线，公式为：

`T = A + K × (A − B)`，其中`K = A到尖端的长度 ÷ A到B的长度`。

原先K固定0.50。本轮增加**全局共享K**：范围0.00～2.00、步长0.01，默认0.50；两种配色共用一份数值，不增加两个独立参数。复位或断电恢复0.50，不写入Flash。

K增加时，准心沿B指向A的方向继续外推；K减小时回到A。它适用于工具实际几何比例与默认0.50不同的情况。K不能把准心任意向上下左右移动，也不能修正错误的颜色中心、失焦、工具弯曲或明显透视误差。比如A/B间距100个原图像素，每次改变0.01约移动1像素；若间距只有20像素，一次约0.2像素，整数坐标可能需要多按几次才改变一格。

所有定位、显示、区域判断及新录制使用同一生效K。更新时等待属于新设置的完整图像，不能把旧准心套上新的K文字。越界时显示尖端不可用，不把结果强行贴到边缘。颜色校准保留，K本身不改变颜色模型。

旧矩形和旧路线保留原来的1倍坐标，不随K重新外推。路线显示**录制时K**；新旧K不同时提示区别。旧路线是当时已经得到的坐标记录，调整K不会把它自动修正成另一条路径。开始新录制收到第一个有效新点后，才同时替换旧路线及录制K标签。

### 已确定的新按键

短按在松手后确认，长按约一秒；组合键应在规定窗口内同时按下，并全部松开后开始下一次操作。

|状态|KEY2短按|KEY3短按|KEY4短按|
|---|---|---|---|
|00普通页|切换亮度档位|切换五档倍率|切换双色配色|
|00的K调节页|退出K调节页|K加0.01，到2.00停止|K减0.01，到0.00停止|
|01矩形编辑|按下锁点、松手确认；第二点自动保存|无短按动作|撤最后一个草稿点；无草稿时逆序删区|
|10实时顺序测试|开始／重测|暂停／继续|FAIL静音|
|11示教|开始／结束录制|开始／从头重播；播放中不暂停|停止回放、解除报警并恢复实时准心|

仅00普通页长按`KEY2+KEY3`进入K调节页。进入组合键不得顺带触发亮度或倍率；页内两键调整也不得触发缩放或配色。切换模式时退出调节页，并消耗未结束的手势。校准、亮度忙和故障期间按状态保护，不能让一次按键同时改变多项设置。

普通页原有KEY2长按标注显隐、KEY3长按跟踪开关、00的KEY2+KEY4校准、KEY3+KEY4方向切换及11的KEY4长按清路线保留。K页仍保留KEY2长按标注显隐和KEY3长按跟踪开关；K加减只在短按松手后执行，长按不连续调K。K页禁用校准和方向组合键，KEY4长按也不清路线。当前K随调整实时应用，退出页面后保留至复位或断电。

## 6. 关于“放大后仍用720p采集”

当前已经是1280×720采集和HDMI输出，前624行视频、后96行底栏。现有放大裁剪较小源窗口，再重复已有像素显示；它不会产生新的真实细节。

Jeremy希望增加放大后的真实细节，需要从传感器原生采样、高清采集或光学入手。该方向先做独立可行性验证，详见[原生细节采集可行性](原生细节采集可行性_20261027.md)。本轮按键／K／亮度修改不代表高清采集已经接入。
