## 确认引脚的方法

1. 记录板卡型号、PCB修订号、芯片封装和摄像头/排线标记，使用对应版本资料。HX1P35A是板型，PH1P35是芯片系列。
2. 逐项追踪"板上器件/连接器针号 → 原理图网络 → FPGA球位 → RTL端口 → ADC引脚约束 → 编译后的IO报告"。例如当前复位端口I_rst_n对应D5/KEY1；D5不是连接器第5针。
3. 同时核对方向、电平、Bank供电（同组IO供电）、上拉、复位极性、差分正负端与通道顺序。FPC核对两端1脚、接触面、40P→24P映射；断电连接。不能只凭针数或排线颜色判断。
4. 用户IO表见[接线与验收](接线与验收.md)。SW1=A4、SW2=B4、上1下0来自手册第21页；本轮IO报告确认输入位置和LVCMOS33约束。DDR/MIPI专用资源还需结合厂家IP配置。
5. 如更换PCB或发现新差异，在项目自有约束中修改并重新编译；不要改只读基线。复查 `build/imagepreprocess_10_3/imagepreprocess_10_3_phy.area` 的Detailed IO Report、时钟和时序报告。报告证明编译采用的映射，实物连接仍由对应PCB资料/检测证明。
6. 保存板卡照片、资料页码、代码提交号、bit哈希与测试结果，按原图、处理模式、复位和连续运行分项验收。

只有出现新的实物版本差异时，才需要向提供方询问（由使用者自行发送）：

> 我使用HX1P35A，PCB标记为【填写】，配套SC500及【排线标记】。当前工程复位D5、按键A9/B9、SW1/SW2为A4/B4。请确认这些与该PCB一致，并提供该版本完整引脚表、原理图，以及摄像头排线映射/接触面/供电和HDMI差分通道表。
