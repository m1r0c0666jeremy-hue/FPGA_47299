## 操作

| 输入 | 功能 |
|---|---|
| KEY1 | 复位至待命，默认原图中心(640,360)、1倍；图像模式仍按SW1/2 |
| KEY2 | SW3=1调亮，SW3=0调暗；一次按住期间锁定方向 |
| KEY3 | 一次按下开启搜索和持续跟踪；再次按下停止，窗口保留当前位置 |
| KEY4 | SW4=1放大，SW4=0缩小，1／2／4倍 |
| SW3=1 | 显示红蓝检测框、A/B中心、T准心及标记说明 |
| SW3=0 | 隐藏视频区检测标注，继续检测和窗口跟随；保留底部状态和标定信息 |
| SW1/2 | 00原图、01边缘、10灰度、11二值化；上=0、下=1 |

KEY3长按不会反复启停。按键约20ms消抖，多键冲突后必须全部释放再操作KEY3。SW3同时控制标注显示和KEY2增益方向，这是已确认的复用方式。

底部状态：待命、搜索中、锁定跟踪、失锁、已停止；按键冲突、视频未就绪作为异常提示。停止跟踪不冻结视频。停止或失锁后不显示旧准心，坐标显示为横线。

## 模型与标定

制作一片硬纸片或直杆，在同一刚性载体上放置前方红标记A、后方蓝标记B和明确的尖端T。三者沿轴线排列：

`蓝B —— L —— 红A —— D —— 尖端T`

- L：两个标记中心的实际距离，单位mm；默认40。
- D：前标记A中心到尖端的实际距离，单位mm；默认20。
- K=D/L：无量纲比例，默认0.5。
- `Tx=Ax+K×(Ax−Bx)`，`Ty=Ay+K×(Ay−By)`；坐标原点在原图左上，向右／下为正。

修改 `rtl/03_tool_detection/target_config.json`，运行 `scripts/generate_target.py`，再重新编译。不要分别手改生成的OSD文字和RTL常数。当前L、D以整数mm配置，L允许1～9999、D允许0～9999；K自动转为16位小数的定点数。中间乘加保留符号，最终坐标一次四舍五入，半值远离零；屏幕K保留3位小数，构建清单同时记录准确的K_Q16。

L=40、D=20只是已选定的模型测试默认值，不是对真实工具的测量结论。移动标记后应重新测量。明显倾斜会有透视误差，两点投影过近时拒绝定位；本版估算尖端，不恢复三维姿态，也不适用于未经建模的弯头或开合工具。

## 检测参数与状态

| 配置项 | 默认值 | 含义（以未缩放原图为准） |
|---|---:|---|
| color_min | 80 | 主颜色通道亮度下限 |
| color_diff | 32 | 主颜色比另外两通道至少高出的数值 |
| ratio_num / ratio_den | 3 / 2 | 主颜色至少为另外两通道的1.5倍 |
| area_min / area_max | 64 / 20000 | 每色合格像素数范围 |
| fill_percent_min | 30 | 同色像素占其包围框面积的最小百分比 |
| separation_min_px / separation_max_px | 16 / 600 | 两色中心距离范围 |
| max_step_px | 96 | 相邻帧两色中心各方向允许的最大变化 |
| confirm_frames | 3 | 开始／失锁后连续合格帧数 |

在白平衡输出的彩色图像上判色，灰度／边缘模式不会切断检测。每色累加像素数量、横纵坐标和及包围框，中心为坐标和除以像素数，向下取整。首版每色只统计一个区域，不具备连通区域分离或多工具身份选择。分散同色干扰可因填充比例失败而被拒绝，但不能保证所有干扰都被拒绝。

初次需要连续3个合格采集帧才锁定；之后逐帧更新。缺色、面积／间距不合格、尖端越界或帧异常时立即撤销该结果的有效位，窗口保持原位；重新连续3帧合格后恢复。不插入位置预测或平滑。显示结果来自对应的已缓存采集帧，不是当前物理时刻的无延迟测量。同一采集帧重复显示不增加锁定计数；显示15帧未见新帧编号时撤销有效准心。

## 数据链路与接口

`相机/ISP白平衡 → 96位彩色旁路检测 → 帧统计/中心 → 尖端与跟踪 → 整包跨时钟传递 → DDR缓存帧号关联 → 显示帧快照 → 窗口/最近邻缩放 → 四模式处理 → OSD → HDMI`

检测旁路不反压相机。96位流每拍四个RGB888像素，**[95:72]对应现有打包和显示序列中的第一个像素**，依次向低位排列。使用有效像素数建立坐标，不用未对齐的厂家行尾。统计到下一次帧起点才结束上一帧，因此少像素和多像素都会被检查。

检测与跟踪位于03、04目录；新控制、窗口管理、行读取及OSD使用target命名模块，保留旧scaling模块和测试作为历史回归。`isp_top`仅增加白平衡流观察端口；`video_in`增加实际写缓存／帧事件／帧号／溢出观察端口。
