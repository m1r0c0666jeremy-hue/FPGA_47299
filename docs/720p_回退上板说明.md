# 720p 回退上板说明

1. 选择本次交付的 `720p_source_coordinates_sram.bit`，核对 SHA256 为 `18fbffee70889073d44f3598029cce8bc5b0662d37f0911e138998315f83844a`。
2. HX1P35A 连接原 SC500CS 摄像头；屏幕通过 HDMI 直连。使用原 TD 下载方式做 SRAM 下载。
3. 观察屏幕能否正常显示 1280×720；旧版时钟理论约 60.606Hz。记录显示器提示和实际识别模式，软件验证不能代替这个测试。
4. 验证 1×、1.5×、2×、3×、4×五档，检查目标框和尖端是否跟随画面，边缘是否错位。高倍率仍是原图取样放大，不增加采集细节。
5. 验证四图像模式、两配色、0°/180°、检测/跟随与校准。新包保留原有操作，不新增数值坐标显示。
6. 记录冷启动、重置、模式切换和连续运行结果；未执行的项目记为待验。

| 操作 | 行为 |
|---|---|
| KEY1 | 全局复位 |
| KEY2 | 按 SW4 方向调整增益；校准中取消 |
| KEY3 短按松手 | 启停检测/跟随；校准中采样 |
| KEY3 长按约 1 秒 | 显隐视频标注 |
| KEY4 | 按 SW4 方向切换五档倍率 |
| KEY2+KEY4 长按约 1 秒 | 停止跟踪时进入四步校准 |
| KEY3+KEY4 长按约 1 秒 | 切换 0°/180°，默认 180° |
| SW1/SW2 | 00 原图、01 目标高亮、10 灰度、11 二值 |
| SW3 | 0 红 A/蓝 B，1 黄 A/紫 B |
| SW4 | 1 增加，0 减少 |

开关沿用原板实测极性：上=0、下=1。组合键近乎同时按下，全部松开后再开始下一手势。

"原 1 倍坐标"指完整 1280×720 源图坐标：X=0～1279，Y=0～719。例如源 (640,360) 在默认 1×、0°的视频区显示位置为 (640,312)，在 180°为 (639,311)，源坐标依然是 (640,360)。底栏和旋转不会写回结果坐标。
