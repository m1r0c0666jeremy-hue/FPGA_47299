# 诊断字段说明

## 选取与诊断

让两色中点位于中央引导区，KEY3短按，等三帧确认。双框不等于有效尖端；缺色或越界时尖端隐藏、窗口停止。遮挡超过15个新采集帧后须回中央重新选取。

- 概况：状态、材料状态、板内延迟/落后帧数、图像F和参数V。
- 判色详情：原始命中→过滤命中，N候选数、Q邻域支持率、S槽位、中心、P选择依据、R拒绝位、C确认进度、L缺失帧、O越界方向位。Q不是识别置信度。
- 参数详情：色相H、亮度M、色差D、相对色差S/16、白平衡R/B、材料N总数/每帧最少数。
- 性能与故障：行耗时/等待（约15ns每拍）、返回/接受字数、DDR/像素故障、恢复数、首错坐标/源行/帧号、相机故障/重试、最后完整应答的增益G；G000表示尚未完成首次应用。相机失败期间G不代表当前半途写入已成功。

板内延迟从解包SOF到该帧首像素进入HDMI编码器，不含曝光及显示器响应。横线表示无效，超过9999.9ms也显示横线。

F、V、R、O及故障E按十六进制显示，与C的`0x`写法对应；命中数、坐标、支持率、时间、增益档位和重试次数为十进制，前导0用于补位。拍照时保留原字符即可。

## 故障数字怎么读

像素故障与DDR故障是两栏独立编号，拍照时同时保留两栏和首错坐标。

| 像素故障 | 含义 |
|---|---|
| 0 | 尚未记录 |
| 1 | 所需源行未准备好 |
| 2 | 缓存源行标签不匹配 |
| 3 | 已选图像银行失效或被复用 |
| 5 | 本显示帧没有有效快照 |

| DDR故障 | 含义 |
|---|---|
| 0 | 尚未记录 |
| 4 | 读任务/返回或排空超时 |
| 6 | 等待写总线让出超时 |
| 7 | 行结果跨时钟通知阻塞 |
| 8 | 收到未预期的读回数据 |

相机故障1=应答失败，2=事务超时，3=没有及时得到完整帧。故障有独立计数和恢复信息，最近记录可在恢复后保留；不能只凭非零旧故障号判断当前图像仍故障。

行耗时是最近完成源行的耗时；总线/返回等待是自复位以来的峰值，包含失败任务，局部流恢复不清除。尚无DDR故障时，接受/返回字数来自最近成功源行；有故障后，与最近DDR故障原因一同保留，后续成功行不会覆盖，直到新故障或KEY1。像素首错与DDR最近故障为两套独立记录，不将其字段冒称为同一采样事件。

## 配对数字怎么读

P：0无候选依据，1中央几何选择，2历史工具连续性选择，3仅供诊断的候选。Q是邻域支持率，不能单独证明识别正确。

R为可叠加的原因位（以下均为十六进制）：01缺有效颜色候选、02中点不在引导区、04间距不合格、08历史位置变化过大、10方向不连续、20间距比例变化、40面积变化、80身份过期。例如R0C表示`0x04+0x08`；R12表示`0x02+0x10`。

O为尖端越界方向：1左、2右、4上、8下，同样可以相加。例如OA表示`0xA=2+8`，即右下越界。坐标和方向按原始源图记录，180°显示时需结合显示方向阅读。
