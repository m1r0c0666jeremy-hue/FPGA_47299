## 标记和校准

| 组别 | 前标记A（靠近尖端） | 后标记B | 用途 |
|---|---|---|---|
| R/Y | 红 | 黄 | 复位后的默认组 |
| B/P | 蓝 | 紫 | 手动选择的备用组 |

00档短按KEY4切组；不会因识别失败自动切换。两组分别保留校准结果，断电后清除。
蓝紫仍可能因材料、光照或相近色相而不稳定，不代表备用组已得到实物改善。

两组都保留原来的白纸、空背景、前标记A、后标记B四步校准和取消操作。
白纸避免过曝；背景步骤移开色标，拍入真实干扰物。暖光、橙色背景是红黄组的重点复测场景。
若提示模型重叠、背景不可分或材料不足，应调整材料／位置并重新采样，不能跳过质量检查。

准心仍按 `T=A+K×(A−B)` 计算。00长按KEY2＋KEY3进入K页，KEY3加0.01、KEY4减0.01，
KEY2退出；范围0.00～2.00，默认0.50。A/B装反会使外推方向错误，K不能修正失焦、误识别或弯曲工具。

## 保留的操作

- 00：KEY2短按切亮度，KEY3短按切1／1.5／2／3／4倍数字放大，KEY4短按切配色。
- 01：KEY2按下锁点、松手确认，第二点自动保存；KEY4撤最后一点，无草稿时逆序删区。
- 10：保留四矩形顺序判断、区内停留、原暂停／静音／重测操作。
- 11：KEY2录制／结束，KEY3播放／从头重播，KEY4停止，KEY4长按清路线；播放中KEY3忽略。
- KEY2长按仍切标注显隐，KEY3长按仍切跟踪；两行底栏继续显示。

本轮没有靠近／远离／静止分析，没有原生高清2倍。视频和底栏仍为624＋96行，HDMI保持720p输出。

## FPS、延迟和故障信息

`FPS060`表示最近一秒新显示的完整有效图像数，**不是HDMI刷新率**。
按同一采集代次的帧号前进统计，忽略重复帧和暂时回退的旧帧；回放虚拟位置不增加FPS。
关闭跟踪或画面内没有工具不应使FPS停止。无新有效图像时，下一统计窗口显示0。
复位后首个统计窗口尚未完成时显示0。

`LAT`继续表示原板内源帧头到HDMI输出的测量，不含曝光和显示器响应。
普通模式用FPS与诊断替换原AGE和长帧编号区域；250毫秒失效保护仍独立工作。

| 字段 | 含义 |
|---|---|
| E00 | 尚未记录运行故障 |
| E1x | 相机故障，低位沿用相机故障号 |
| E2x | DDR恢复监督原因 |
| E3x | DDR读事务故障；E31也用于意外返回记录 |
| E4x | 像素读行／欠载原因 |
| R0000 | DDR恢复次数，四位十六进制；FFFF为饱和值 |
| L0／L1 | 是否曾在相机就绪后观察到lane标志 |

E和R均按十六进制显示。故障码恢复后保留，出现下一故障时更新，全局复位清除。
L仅提供线索，其语义未获厂商完整说明，**不是CRC错误或坏帧计数，不触发额外复位或丢帧**。

校准状态把统计移到首行调试编号区，第二行完整保留采样／重试／取消提示。
示教顺序启用时保留NEXT、IN、T及结果，统计放在原空白位置；SEQ OFF时仅放紧凑FPS/L，
完整E/R可切00查看。终止相机故障文字优先显示。

底栏字符和显示资格采用同一帧快照，状态在扫描途中改变不再擦除当前文字。
新文字最晚下一底栏更新；实际图像拒绝、位置失效、录制停止和报警保护不会等待文字更新。
