## 操作

| 输入 | 行为 |
|---|---|
| KEY1 | 复位待命、中心(640,360)、1倍、标注显示；稳定后的SW3决定配色 |
| SW3=0（上） | 红A前、蓝B后 |
| SW3=1（下） | 黄A前、紫B后 |
| KEY3短按 | 不足1秒，松手后开启／停止跟踪 |
| KEY3长按 | 满1秒只切换标注显隐一次；继续按住与松手不再次动作 |
| KEY2 | SW4=1调亮、SW4=0调暗；按住锁定方向，保留150ms连发 |
| KEY4 | SW4=1放大、SW4=0缩小；1/2/4倍，保留600ms连发 |
| SW1/2 | 00原图、01边缘、10灰度、11二值化 |

长按时间从按键消抖后确认按下计算，短按不在按下瞬间启动。按键消抖约20ms，多键冲突取消未完成的KEY3手势，全部释放才重新响应；复位时按住也要先释放。长按可在待命时预设显隐，隐藏仅作用于视频区，底栏状态、配色、坐标、标定和Logo始终保留。

颜色切换立即废弃旧会话结果。已开启跟踪时固定当前观察中心并重新搜索，连续3个新配置的合格采集帧后恢复跟随；已停止时不自动开启。停止／失锁隐藏旧标注，视频继续刷新。KEY2不再使用SW3，避免调增益时意外换色。

## 中文显示

视频区显示“红色标记点A／蓝色标记点B”或“黄色标记点A／紫色标记点B”。准心旁两行显示“十字准心T／估算尖端”，不将推算值称为真实尖端测量。

采用24像素字模、黑色底板，标记框／中心点与配色一致，准心黄色黑边。标签先尝试框上方／下方及对齐后的备用位置，B还尝试两侧；顺序为T、A、B，避让失败后使用视频区左上角固定说明区。所有文字裁剪在1280×624视频区，不进入底栏；框或准心完全在观察窗外时不绘制其标签。底栏显示当前配色及标注开关，仍保留安路Logo。

## 模型与参数

两套模型均为 `后标记B —— L —— 前标记A —— D —— 尖端T`。默认L=40mm、D=20mm、K=0.500；更换标记必须保持中心位置，若移动中心则重新标定。颜色切换不是自动识别标记身份，不支持多工具选择、三维姿态恢复或同色区域分离。

编辑 `rtl/03_tool_detection/target_config.json`，运行 `scripts/generate_target.py`，再重新编译；不要手改生成的OSD、字模或采集包装模块。

| 参数 | 默认值 | 用途 |
|---|---:|---|
| color_min / color_diff | 80 / 32 | 原红蓝主通道亮度和差值，保持旧判据 |
| ratio_num / ratio_den | 3 / 2 | 红蓝通道优势1.5倍 |
| yp_min / yp_diff | 80 / 24 | 黄紫的双强通道最低亮度及相对弱通道差值 |
| yp_ratio_num / yp_ratio_den | 5 / 4 | 黄紫较弱的强通道至少为弱通道1.25倍 |
| yp_balance | 2 | 黄紫两个强通道最大／最小比例上限 |
| long_press_ms | 1000 | KEY3长按阈值，毫秒 |
| area_min / area_max | 64 / 20000 | 每色通过判色的像素数量 |
| fill_percent_min | 30 | 合格像素占该色包围框面积的百分比下限 |

黄色用R、G作为两个强通道，B为弱通道；紫色用R、B作为强通道，G为弱通道。整数运算扩位，无浮点运算。所有判据必须同时满足；初值仍待实物色环验证，暗紫／低饱和紫可能需要调参，不保证黄色或紫色背景不会误锁。先固定照明、对焦及背景作对照，不一次性放宽所有参数。

原间距16～600像素、单帧位移96像素、3帧确认及15显示帧新鲜度检查保持。标记无需圆形，明显倾斜时尖端外推精度仍有限。

## 配置与帧对应

控制跨时钟指令从9位扩展为10位：`{pair,session[7:0],enable}`，保持整包握手。采集SOF锁定此配置，当前帧四像素统计均使用同一配色；下一SOF输出上一帧时，使用上一帧的原始配置。配置在计算中变化不能重贴旧帧标签。

256位结果包原坐标／帧号／原因位置保持不变，235～242位改为明确的“采集帧会话”，243位为配色（0红蓝／1黄紫），244位为采集帧启用标志；184～223位为A／B合格像素数量。其余保留位仍为0。跟踪和显示均验证会话及配色，旧结果即使迟到也不得驱动窗口。

显隐及底栏配色在显示VS边界提交，不依赖DDR快照是否返回。中文标签布局使用短流水线，在消隐期收到稳定窗口后逐级安排T、A、B位置。
