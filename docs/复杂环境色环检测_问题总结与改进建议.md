# 复杂环境下「色环目标 → 尖端 → 跟踪放大」：本轮问题总结与改进建议

日期：2026-10-13　被测版本：`target_color_regions`（UI `R1-01`，bit SHA256 `87956070e9ddfb8d1c3c56cef5adf830b6513b34e9f1d3cd4a5ff2554d8a1e0f`）
基线：`LockingnTracking @ e82a62f`（工作区含未提交的功能改动，本文件所在分支即为该快照 + 本文件）

---

## 0. 目标与现状

**目标**：在**复杂环境**中检测出**带色环的物体** → 由色环几何**算出尖端** → **跟踪并放大**显示。

**现状**：
- 判色 + 连通区域 + 双色双框 + 底栏（模式/倍率/配色/候选/状态/RGB）链路**已跑通**；
- 但**尖端估算与自动跟随放大链路被移除**（`target_color_regions.al` 的模块清单里没有 `target_tracker.v` / `target_display.v`）；
- 本轮实物测试暴露出：复杂（尤其偏暗、杂乱）背景下判色与选区**会被噪声淹没**。

## 2. 问题总结（按对目标的影响排序）

### P1（致命）判色门槛过低，暗部噪声被判定为红/紫/蓝
- **证据**：图 6/7/8/9/11 的满屏彩色噪点全部落在暗区；图 9 底栏 `RGB:048/036/048` 可反推：
  m=48、d=12 → `min_value≥24` ✓、`min_chroma≥8` ✓、相对饱和度 `16·d≥3·m`（192≥144）✓、
  mx=R 且 G<B → 落入**紫色区间 255–330°** ✓ → **四道门全过，被判成"紫色"**。
- **后果**：区域数爆炸 → `区域拥挤` / `更多区域待判` → **真正的大色块被挤出两个槽位**（图 5/6/7 的印刷卡正是如此）。
- **本质**：判决用的是**相对**饱和度（3/16），暗噪声的相对饱和度很容易达标；而**绝对亮度门槛只有 24**。

### P2（致命）缺少"唯一工具"约束
系统现在输出的是"区域"，而不是"一个带色环的物体"。复杂背景下候选必然饱和（现在每色只有两个局部槽），
于是"先到的小碎块"占满槽位，真目标反而没有框。缺少：形状筛选、成对几何约束、评分与唯一选择。

### P3 色相区间与常见背景重叠
- **紫 255–330°** 与"R≈B>G"的灰紫噪声高度重合（图 8/9 全中此陷阱）；
- **黄 45–75°** 与米白/纸色/木色相邻（图 3/11 的黄与纸面接近）。
- 初始区间是**工程初值，未用实物样本标定**（文档已声明），复杂背景下必然需要收窄或重标定。

### P4 印刷件/纸张纹理与摩尔纹把色环切碎
图 5/6/7：纸面半色调网点 + 摩尔纹 + 反光 → 一个色环被切成多个连通区域 → 计数与槽位被占满。

### P5 空心环本身对"面积/填充"类判据不友好
色环是空心的，`fill`/支持度类判据容易把环判成碎片；反过来，**空心 + 环带**恰恰是"色环物体"最有辨识力的特征，
当前没有被利用。

### P6 尖端与自动跟随放大链路缺失（与目标直接冲突）
`target_tracker.v`（含 `Tx=Ax+K(Ax−Bx)` 尖端估算、`SEP/MAX_STEP/CONFIRM` 语义）与
`target_display.v`（窗口/倍率/快照）**仍在仓库中**，但未进入本版编译清单。

### P7 显示关联与三帧确认带来滞后
结果与显示图像跨时钟关联、首次确认需连续 3 帧、显示可能落后一采集帧——跟踪放大时必须配合**死区/平滑**策略，
否则窗口会追着噪声跳。

### P8 诊断信息偏少
底栏有状态/候选/RGB，但**没有"为什么没出框"的原因码**（帧不完整/缺色/面积/填充/间距/越界/跳变），
现场只能靠猜。参考实现见另一分支 `docs/颜色检测优化_测试分支说明.md`（未锁定时显示 `E<原因码>` 与 A/B 命中）。

## 3. 面向目标的改进建议（分五阶段，可独立验收）

### 阶段 A：判色层（**只改 JSON**，风险最低，先做）

阈值全部在 `rtl/03_tool_detection/target_config.json` 的 `regions_*` 键，改完运行
`scripts/generate_color_regions.py` 再编译即可（`rtl/color_regions/regions_classifier.v` 是生成文件）。

| 键 | 当前 | 建议 | 依据 |
|---|---|---|---|
| `regions_min_value` | 24 | **64** | 暗噪声 m≈30~50 出局；材料（红/蓝环 m≈150、黄块 m≈200、纸上红 m≈170）保留 |
| `regions_min_chroma` | 8 | **24** | 噪声 d≈8~15 出局；材料 d≥60 保留 |
| `regions_purple_lo` | 255 | **270** | 避开 R≈B>G 的灰紫噪声（图 8/9）|
| `regions_yellow_lo` | 45 | **50** | 与米白/纸色拉开（图 3/11）|
| `regions_tile_min` | 4 | **6~8** | 粗网格块内需更多命中像素才算，抗散点 |
| `regions_support_min` / `regions_area_min` | 16 / 16 | **24~32** | 丢弃小碎块，避免占满槽位 |

⚠️ 边界：
1. `regions_sat_num/den` 被生成脚本**硬断言为 3/16**（相对饱和度门槛动不了，需改 RTL 移位通路）；
2. 抬高 `min_value` 会牺牲**很暗的深蓝/深紫材料**（测试清单里有"暗蓝/暗紫"），64 是折中起点；
3. **不要为了复杂背景无限放宽所有门槛**——那会把噪声一起放进来（本轮已经证明）。

### 阶段 B：区域层——从"色块"升级为"色环物体"

- **B1 空心环特征**（用"填充率低 + 环带支持度高 + 孔洞占比"来**筛环**，而不是要求实心）；
- **B2 成对约束**：A/B 两色中心距落在 `[SEP_MIN, SEP_MAX]`（按标定的 L/D 换算像素）、面积比范围、
  **共线性**（两色中心连线方向一致）；
- **B3 唯一选择**：在候选集合上按**评分**（面积 × 环状度 × 成对几何一致性）选出**最优一对**，
  并加迟滞防止来回跳；输出"唯一工具"标志；
- **B4 抗切碎**：对同色掩码做**闭运算/桥接**（合并被文字、摩尔纹切开的相邻区域）后再做连通域统计；
- **B5 抗噪**：粗网格"块命中比例 + 区域支持度/面积下限 + 连通域数量上限"三件套。

### 阶段 C：几何层——尖端

- 直接复用 `target_tracker.v` 的 `Tx=Ax+K(Ax−Bx)`（K 由 L/D 标定）——**已存在，接回即可**；
- 更稳的做法：用**环的几何中心**（孔洞中心/外框中心）而不是灰度质心；
- 进阶：用**两色中心连线的方向**估计轴线，尖端沿轴线外推（比单轴 K 更通用，可处理旋转）。

### 阶段 D：跟踪与放大

- 用尖端驱动显示窗口（复用 `target_display.v` 的窗口/倍率/快照逻辑）；
- 增加**死区 + 最大步进 + 一阶平滑**，避免追噪声抖动；保留 `confirm=3` 与 `max_step` 语义；
- 失锁 → 固定窗口；恢复 → 重新三帧确认（现有语义可直接沿用）。

### 阶段 E：诊断与验收

- 底栏增加**原因码 + A/B 命中数**（另一分支已实现同类诊断，可移植）；
- 建立**分场景验收矩阵**（见第 5 节）与指标口径；
- 记录模板沿用 `reports/color_regions_hardware_record.csv`。

## 4. 立即可做（零改动 / 现场）

1. **让背景亮起来、干净起来**（当前下半屏是暗桌面 + 线材）：加白纸/挡板，或抬高相机只拍墙面——噪点会大幅减少；
2. **材料移到画面中心并填满绿色采样框**（图 1/2 是正确用法），保证 RGB 读数取的是材料而不是暗背景；
3. **印刷件换哑光纯色材料**（纸面半色调 + 摩尔纹会切碎色环，图 5/6/7）；
4. **对焦清晰、避免高光/过曝**（过曝压掉饱和度）；
5. 黄/紫记得 `SW3` 下=1；隐藏用 `KEY3` 长按 1 秒。

## 5. 验收矩阵与指标（建议写进下一轮测试）

**场景矩阵**：{黑底发光色环 / 白纸印刷 / 白纸哑光贴纸 / 复杂暗背景 / 复杂明亮背景} × {红蓝, 黄紫} × {静止 10s, 缓慢平移} × {1×, 2×, 4×}

**指标**：
- 检出率（每场景 10 次进场，出框次数）；
- **误检区域数**（每帧非目标区域个数，本轮为"爆表"）；
- 尖端误差（相对已知几何的像素误差，≤ N px）；
- 跟踪抖动（静止时窗口/尖端峰峰抖动 px）；
- 失锁/恢复帧数（遮挡 → 重新确认所需帧数）；
- 首次确认帧数（进场到出框的帧数）。

## 6. 不建议做的事（避免走偏）

- ✗ 为复杂背景无限放宽所有门槛；
- ✗ 用"把全屏同色像素包成一个大框"来提升检出率；
- ✗ 没有实物样本就说"色环识别已修复"；
- ✗ 拿手机色卡结果当实体材料验收。
