# 单色候选框与测试诊断

后续已加入帧头修复和宽范围颜色参数，当前入口见 [采集修复与宽范围判色](LockingnTracking采集修复与宽范围判色.md)。本文以下内容保留为f395cc0阶段记录。

更新：2026-10-10。开发于LockingnTracking的a8681a2。本次新增的是独立候选显示，未放宽颜色门限，也没有增加滤波、HSV、多目标分离或修复旧采集链路。

## 操作和观察

短按KEY3开启后，任意一种颜色满足面积和填充率要求，就会显示自己的框、中心和中文名称。两种颜色都出现但尚未锁定，也可以看到两个候选框。**候选框不是工具锁定证明**：只有双色配对、尖端范围及连续3帧检查通过，才显示估算尖端并跟随窗口。

| 情况 | 画面 |
|---|---|
| 只有A合格、B没有通过判色的像素 | A框，诊断“缺少B” |
| 只有B合格、A没有通过判色的像素 | B框，诊断“缺少A” |
| 两色都没有合格像素 | 不画框，诊断“缺少双色” |
| 有颜色像素，但数量或填充率不合格 | 该色不画框，面板保留统计，显示面积不符／填充不足 |
| 两色候选合格，但几何不合格 | 两框，显示间距不符／尖端越界等；不画尖端、不移动窗口 |
| 正在累计连续合格帧 | 候选框，诊断“确认中” |
| 双色锁定 | 两框及尖端，诊断“已锁定”，窗口跟随 |
| 锁定后其中一色消失 | 隐藏尖端，保留仍合格的候选框，固定窗口并继续搜索 |
| 停止跟踪 | 隐藏候选框、尖端和测试面板，保持窗口、视频继续刷新 |

SW3上=0红A／蓝B，下=1黄A／紫B；KEY3长按1秒显隐视频区全部标注及测试面板，继续检测跟随。KEY2按SW4调增益，KEY4按SW4缩放，KEY1复位规则不变。

面板在视频区左下方（544～615行），显示A/B合格像素数、包围框填充率和各自状态。填充率是合格像素数除以包围框面积，取整数百分比，**不是识别置信度**。面积边界仍64～20000，填充率至少30%，依据原始1280×720采集坐标，与显示倍率无关。数量过少、过多和空区域均不冒充有效候选。

显示统计只取与当前DDR图像、采集帧号、配色、会话一致的结果；缺少匹配结果显示“等待结果”和横线，不使用其他采集帧凑数。坏采集帧可显示“帧无效”，但不得画候选框；若DDR本身没有完整可用图像，仍显示底栏“视频未就绪”，并非本功能能够绕过的条件。候选框完全在放大窗口外时不会显示，需要缩小查看。

| 路径（相对仓库） | 变更 |

| rtl/03_tool_detection/target_detector.v | 分别判断A/B候选；缺色仍计算另一色中心和填充率；复用串行除法器 |

| rtl/10_memory_video_out/memory_video_out.v | 连接独立检测有效位至OSD |

保持256位结果包。新增245位A候选、246位B候选、247位采集帧完整有效；224～230位A填充率、248～254位B填充率，255和231仍保留。32位仍是双色总有效／跟踪后尖端有效，原面积、中心、包围框、帧号、会话和配色位置不变。帧无效／溢出原因优先保留，不被缺色或面积错误覆盖。统计计算由4个中心分量扩展为6次串行除法，约两百拍，不能用旧测试的过短等待时间判断结果丢失。

## 构建与验证

使用新独立工程 `td_project/target_lock_candidates.al` 和 `scripts/build_target_lock_candidates.tcl`，输出 `build/target_lock_candidates/target_lock_candidates.bit`。原dualcolor工程已有用户／TD设置改动，本次保留；新工程在其文件依赖基础上加入diagnostics模块。不要用旧输出目录覆盖归档bit。

测试入口：`scripts/test_candidate_unit.py --full`、`test_candidate_detection.py`、`test_candidate_full.py`、`test_candidate_video.py`、`test_candidate_osd.py`、`test_candidate_regression.py`。审计 `scripts/audit_candidates.py`，先用--snapshot保存输入，构建完成后--record-build记录证据，之后无参数复核。测试日志前缀candidate，OSD预览在 `reports/candidate_preview/`。详细最终结果见 `reports/LockingnTracking单色候选验证报告.md`。

本次仍为联调版本。已有帧头复位丢数据、花屏原因及手机色卡／离焦依赖没有因增加候选框而修复。实物先确认视频正常、底栏配色正确，再遮住B观察A、遮住A观察B、恢复双色验证锁定；检查隐藏、停止、换色及放大窗口边界。新增统计能帮助定位失败条件，不保证手机色卡或任意实体颜色必然通过。
