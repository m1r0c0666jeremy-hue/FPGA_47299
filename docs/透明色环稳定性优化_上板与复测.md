# 透明色环稳定性优化：上板与复测

本版增加材料/背景联合校准和同帧诊断，保留现有双色工具、尖端公式及跟随规则。只下载最终验证报告指定的新 bit；旧正式 bit 不支持以下四步流程。`.al` 是工程入口，不是烧录文件。

## 开关与按键

开关上为0、下为1。{SW1,SW2}：00原图、01色彩高亮、10灰度、11色彩二值。SW3上红A/蓝B、下黄A/紫B；A靠近尖端，B在后方。SW4上调暗/减倍率，下调亮/增倍率。

| 操作 | 按键 |
|---|---|
| 复位：待命、1倍、标注开、180°、概况页 | KEY1 |
| 选取/停止；校准时确认当前步骤 | KEY3短按松开 |
| 框/标签显隐（底栏保留） | KEY3长按1秒 |
| 调亮度，暂停跟随并要求重校准两配色 | KEY2 |
| 1、2、4倍步进，到端点保持 | KEY4 |
| 待命进入校准 | KEY2+KEY4一起长按1秒 |
| 0°/180°显示方向 | KEY3+KEY4一起长按1秒 |
| 概况→判色详情→参数详情→概况 | KEY2+KEY3一起长按1秒 |
| 校准取消，保留上一套完整参数 | KEY2 |

组合键的第二键需在第一键被识别后100ms内加入。推荐一起按下；动作后全部松开再操作。短组合、迟到的第二键、三键同时按下不触发组合功能。组合期间不执行亮度、倍率、选取及显隐。方向和页面在下一显示帧生效，底栏文字/图标始终正向。旋转只影响显示，检测和跟随使用原始坐标。

## 四步校准

1. 固定相机增益、光照、拍摄距离和背景，选择当前配色。先短按KEY3停止到待命；同时长按KEY2+KEY4进入。校准临时回中央1倍原图。
2. **白纸**：让源图中心16×16采样框完全覆盖均匀白纸，避免阴影、镜面反光和过曝。短按KEY3，保持稳定，等待八个完整帧及串行计算完成。
3. **空背景**：移走工具和白纸，保留实际检测背景。此步抽样整幅图像，不只是中心小框。短按KEY3并保持背景不动。
4. **A色**：将靠尖端的红色/黄色材料覆盖中心采样框。环孔不必填满，但需每帧至少16个有效材料像素、八帧总体至少256个。短按KEY3并保持位置。
5. **B色**：将后方蓝色/紫色材料移到中心框，短按KEY3。全部成功后才发布完整参数，回待命并恢复原页面/倍率。

每步需八个完整帧，处理期间不要重复按确认。两配色分别校准；切配色会中断当前未完成校准。取消/失败不会发布半套参数。换页面、倍率、启停及方向保留参数；复位/断电恢复默认；亮度改变将两组标为需更新。背景、材料或照明明显改变，应重新执行四步。

透明环在黑笔管上过暗、色差太小，或与背景具有相同颜色分布时，可能明确拒绝校准。这表示当前样本难以可靠区分，不是已解决实物问题。调整照明、避免反光、使采样窗更多覆盖材料，再重试；背景不可分时建议取消并重新执行全部四步。

## 底栏解释

右侧为安陆官方图形。概况行显示页面、倍率、配色、方向、工具/校准状态与中心RGB。RGB仅代表中心8×8统计，不能推断全屏假命中像素。第二行F是图像帧号（十六进制），V是参数版本，A/B为选中区域的支持像素总数/局部支持率。

判色详情：`A/B 原始数>过滤数 N候选数 Q局部支持率 S选中槽位 F处理阶段`。N最多4；S从0开始。Q表示命中像素中至少两个同色邻居的比例，**不表示识别置信度**。P为选取依据：1中央、2历史身份、3单色独立显示、0无。C为连续确认进度，L为缺失采集帧数，R为配对拒绝位图（十六进制）。任一有效配对存在时R清零。

| F阶段代码 | 含义 |
|---|---|
| 1 | 分类没有命中 |
| 2 | 命中全部被去孤立滤除 |
| 3 | 未形成核心网格 |
| 4 | 区域面积/尺寸不合格 |
| 5 | 有合格候选，需继续看配对与确认状态 |
| 6 | 异常/不完整帧 |
| 7 | 网格处理失败/超时 |
| 9 | 正在校准或当前参数需更新 |

R位从低到高依次为：缺色、引导区、间距、位置跳变、方向、间距连续性、面积连续性、身份过期。R可能汇总多个被拒绝的组合。单色框仍存在时，尖端可能无效，不以框数判断跟踪成功。

参数详情：H色相范围（允许红跨0°）、M亮度下限、D色差下限、S相对色差分子/16；R/B白平衡增益以1024为单位；T网格处理拍数，Z丢失/替换结果数（封顶32767）。校准提示优先于手动页。缺少同帧结果的字段显示横线，不能当作零命中。

校准E错误：01异常帧、02白纸质量不足、03增益超范围、04混色或采样不足、05模型重叠、06背景不可分、07材料保留不足、08采样窗暗部过多、09亮度改变、0A中性弱色差过多。08/0A描述采样窗，不等同于真实材料全体像素。

## 最小实物复测

使用 `reports/transparent_ring/hardware_retest.csv`。每次记录板上bit SHA256、相机增益、光照、背景、材料、校准是否成功、F/V、命中/候选/支持率、选中区域和失败阶段；保留照片与连续视频。

| 场景 | 最少操作 |
|---|---|
| p1金属尖端、p12纸面文字 | 各3次中央选取，记录错误B候选和最终选中框 |
| p2/p3黑背景、p5/p6 PCB紫噪声 | 各3次，记录原始/过滤数、候选数、Q和F |
| p11假黄色 | 3次，确认真实A是否进入候选以及P选择依据 |
| 黑笔管透明环 | 两配色各重校准、选取、静止和缓慢移动 |
| p8/p10/p13成功样例 | 各3次选取并录静止/移动，不能只看消噪效果 |
| 黑台面、白纸、PCB空场 | 两配色各60秒，记录任何有效尖端误显示 |
| 遮挡与恢复 | 两配色分别验证短暂缺色、超过15采集帧、回中央重选 |

从待命将工具放到中央引导区，短按KEY3。正常双色需连续三帧确认；缺色立即隐藏尖端并冻结窗口，身份保留15个新采集帧，恢复需重新连续三帧匹配。超期不会自动切到其他工具；先停止到待命，再回中央启动选取。L与D几何比例应为0.5，尖端公式仍为`T=(3A-B)/2`。

此版本没有相机原始帧导出接口。手机拍屏用于观察现象，不能作为FPGA原始RGB真值。软件、TD构建与实物结果分别记录；未执行的实物指标标待验，不推算90%识别率。
