# 采集帧头修复与宽范围判色

日期：2026-10-10。基于LockingnTracking的f395cc0；本轮保留用户／TD已保存的 `target_lock_candidates.al` 设置，在独立robust工程构建。

## 本轮变化

旧版AWB的帧起点与第一个有效四像素字可以同时出现；96→128打包后，第一批有效字已经进入FIFO，DDR域才收到展宽帧起点并复位FIFO。复现输入1280×4像素，打包960字，DDR只写720字。缺少的不是整整240个输入字，而是帧头部分数据被清除后，剩余数据不足最后一个240字突发，导致写入总数少一个突发。

`user_source/hdl_source/video_in.v` 现在采用请求／应答复位流程：

1. 相机域先把新帧数据暂存到256×128位RAM（4096字节），同时固定帧号并发送请求。
2. DDR域停止旧帧读FIFO，等待最后一个已登记写请求完成，再复位FIFO。旧帧写入不会带着新帧地址提交。
3. 发布新帧的缓存编号与帧号，留出复位释放时间，返回应答。
4. 相机收到同步后的应答，再将暂存数据按顺序送入原跨时钟FIFO。后续仍采用240字DDR突发，不暂停相机。

新帧起点与第一个数据字同时到来也会保存该字。若DDR长期不服务导致有限暂存区溢出，整帧标为异常；短帧仍不能作为完整图像显示，下个正常帧重新恢复。没有放松172800字完整帧检查。固定时钟倍率及行为模型验证不能替代厂家物理FIFO、板上时钟与布线验证。

该修复针对已复现的960→720缺陷。重插摄像头线后曾恢复的闪屏，仍可能同时涉及接线、供电或其他链路问题，不能据软件测试认定所有闪屏原因都已消除。

## 新颜色参数

实际生产参数统一来自 `rtl/03_tool_detection/target_config.json`。表中RGB均指白平衡之后相机实际输出的0～255通道值；拍显示器的照片不能直接当成这些数值来标定。

`target_capture_pipeline.v` 由生成器把这些参数显式传入检测和跟踪模块；可复用模块声明中的历史默认值不代表当前板级实例使用的值。旧窄阈值单元测试仍保留，作为算术兼容性回归。

| 项目 | 旧值 | 新值 |
|---|---:|---:|
| 红／蓝主通道最低值 | 80 | 40 |
| 主通道至少高于另两通道 | 32 | 12 |
| 主通道与另两通道最低比例 | 1.5 | 1.125（9/8） |
| 黄／紫两个强通道最低值 | 80 | 40 |
| 两强通道较小值高于弱通道 | 24 | 12 |
| 较小强通道与弱通道最低比例 | 1.25 | 1.125（9/8） |
| 两强通道最大不均衡比例 | 2 | 4 |
| 每色最小有效像素 | 64 | 32 |
| 每色最大有效像素 | 20000 | 921600（整帧） |
| 最小填充百分比 | 30 | 0（只显示，不作硬拒绝） |
| 两色中心最大间距 | 600像素 | 1468像素（覆盖完整画面对角线） |

红色要求R为主，蓝色要求B为主；黄色要求R/G高于B，紫色要求R/B高于G。比较先扩位，不会因255附近通道相加或比例乘法溢出而误判。深红、浅红、深蓝、浅蓝及深浅黄紫有更宽的通过范围，但非常接近灰／白、过暗或颜色通道关系已经改变的物体仍可能不通过。

**现在面积大于20000不会因此被拒绝。** 两种颜色独立统计，不要求圆形、相同半径、面积相等或固定面积比例。空区域和少于32个像素仍被拒绝，避免零星噪点直接作为标记。

**填充率保留显示，但默认不再阻止画框或锁定。** 小于1%显示整数000%，并不一定代表没有颜色像素；先看左侧像素数。若需要恢复筛选，可把 `fill_percent_min` 从0改为5、10或其他测试值后重新生成、构建。

当前仍是“每色一个全画面汇总候选”，不是多个独立色块的分离器。蓝色文字、蓝色连线、远处同色物体可能扩大包围框并拉偏中心。放宽阈值和取消填充硬拒绝能够让之前被条件挡住的结果显示，但不能保证框选的是唯一正确物体；用无同色干扰背景检查框和中心点。若此时框仍跨越多个物体，下一步应做连通区域或指定区域选择，不能继续无限放宽阈值。

## 中心、间距和操作

每个标记中心采用其全部合格像素的平均坐标：`cx=Σx/N`、`cy=Σy/N`，即像素重心。均匀实心圆或矩形的重心在色块中心；比直接取全局包围框中点更不易被少量远处点拉偏，但同色背景很多时仍会偏移。间距取A、B中心之间的欧氏距离，不取边缘间距，也不以两色尺寸相同为前提。

尖端仍用 `T=A+0.5×(A−B)`，L=40mm、D=20mm保持。两色投影间距至少16像素、尖端在画面内、位置变化检查和连续3个完整采集帧确认保留。大色块可以显示单色框，但只有一色、尖端推到画面外或移动过快时仍不会锁定。

SW3=0红A／蓝B，SW3=1黄A／紫B；KEY3短按启停，长按1秒隐藏／显示标注和诊断面板；KEY2按SW4调增益，KEY4按SW4缩放，SW1/2四模式不变。
