# 本轮测试版上板一页说明

**仅使用最终交付清单所列新bit。当前构建未完成，本页先记录操作方法。** 原历史bit、工程和Flash内容保留；尚未执行板卡下载或实物验收。

## 1. 启动与按键

上电默认180°、1倍、待命。等图像就绪，再操作。KEY3短按中央选取/停止，长按1秒显隐标注。倍率由KEY4调整：1→1.5→2→3→4，到端点保持；SW4下为增加，上为减小。KEY2按SW4方向调亮/调暗，随后两配色都需要重校准，跟随暂停。

组合键长按1秒：KEY2+KEY4进入校准（待命时）；KEY3+KEY4切0°/180°；KEY2+KEY3切四页底栏。全部松开后再操作。KEY1复位恢复默认，清除校准。

SW1/SW2：上上原图、上下高亮、下上灰度、下下二值。SW3上红A/蓝B，下黄A/紫B。A始终靠近工具尖端。

## 2. 四步校准

待命，KEY2+KEY4长按1秒进入。各步摆稳后KEY3确认，每步采八个完整帧；KEY2取消。

1. 白纸：A4纸覆盖中央绿框，避免阴影或过曝。
2. 实际空背景：移走双色标记，保留工作背景；中央小绿框对准易误检的文字、裸笔杆或金属区域。
3. A：保持实际安装、衬底和姿态，把近尖端色放到中央绿框。
4. B：同样采后方色。透明环套黑笔使用时，两步均连同黑笔一起取样。

完成后回待命，原倍率恢复。背景、光照、安装方式明显变化或调过亮度，重新校准当前配色。失败/取消保留旧完整模型；提示“需要更新”时不跟随。暗部、弱色差、背景不可分时调整照明/材料或取样姿态后重采。拍一张参数页，保留版本V及N总数/每帧最少数。

## 3. 选取和看诊断

让两色中点位于中央引导区，KEY3短按，等三帧确认。双框不等于有效尖端；缺色或越界时尖端隐藏、窗口停止。遮挡超过15个新采集帧后须回中央重新选取。

- 概况：状态、材料状态、板内延迟/落后帧数、图像F和参数V。
- 判色详情：原始命中→过滤命中，N候选数、Q邻域支持率、S槽位、中心、P选择依据、R拒绝位、C确认进度、L缺失帧、O越界方向位。Q不是识别置信度。
- 参数详情：色相H、亮度M、色差D、相对色差S/16、白平衡R/B、材料N总数/每帧最少数。
- 性能与故障：行耗时/等待（约15ns每拍）、返回/接受字数、DDR/像素故障、恢复数、首错坐标/源行/帧号、相机故障/重试、最后完整应答的增益G；G000表示尚未完成首次应用。相机失败期间G不代表当前半途写入已成功。

板内延迟从解包SOF到该帧首像素进入HDMI编码器，不含曝光及显示器响应。横线表示无效，超过9999.9ms也显示横线。

## 4. 最少拍摄与记录

黑笔透明环、纸面文字、PCB紫噪声、手部干扰、平放打印、遮挡恢复：两配色分别三次中央选取，记录成功/误选/掉框；每场景拍高亮概况和判色详情各一张，保留最差状态。参数改变后补拍参数页。

黑闪/冷启动录连续视频，并补拍性能与故障页。确认临时下载正常后，由Jeremy执行Flash冷启动复测。空场两配色各观察60秒。保留原成功样例对照。

每条记录填新bit哈希、材料、背景、光照、增益、参数版本。手机照片用于记录现象，不能当作相机原始RGB。软件通过、构建通过、实物通过分别记录。
