# 使用手册

本页对应 `LockingnTracking` 分支的双色工具定位与单色候选显示。工程与下载路径见 [编译与下载](BUILD.md)。

## 连接与启动

1. 使用 HX1P35A 开发板和配套 SC500CS 摄像头，断电连接摄像头排线，检查接触面和供电。
2. 用 HDMI 连接显示器，用下载器连接板卡。
3. 按本分支 README 选择 bit 文件，用 TD 的 BitWriter 下载到 SRAM。SRAM 是临时配置，断电后失效；Flash 配置会在下次上电加载。
4. 松开所有按键后按 KEY1 复位，先确认原图能连续显示，再调整图像和功能模式。

## 开关与按键

表中开关按电平写为 0 和 1。既有板上记录的方向是上 = 0、下 = 1；首次使用仍应核对底栏与板卡修订。KEY1 为复位键。

| 输入 | 功能 |
|---|---|
| SW1 SW2 = 00 / 01 / 10 / 11 | 原图 / 边缘 / 灰度 / 二值图 |
| SW3 = 0 / 1 | 红 A、蓝 B / 黄 A、紫 B |
| SW4 = 1 / 0 | 增加 / 减少增益或倍率 |
| KEY1 | 复位 |
| KEY2 | 按 SW4 调节相机增益；校准中取消 |
| KEY3 短按松手 | 启停检测；支持校准的版本中确认取样 |
| KEY3 长按约 1 秒 | 显隐视频标注，底栏保留 |
| KEY4 | 按 SW4 切换 1、2、4 倍，到端点保持 |

材料条件、实现细节和本版专项验证见 [详细说明](LockingnTracking单色候选与帧头修复.md)。
