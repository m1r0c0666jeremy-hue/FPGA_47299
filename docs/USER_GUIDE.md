# 使用手册

本页对应 `Behaviour_region_1024` 分支的矩形区域示教与顺序检查。工程与下载路径见 [编译与下载](BUILD.md)。

## 连接与启动

1. 使用 HX1P35A 开发板和配套 SC500CS 摄像头，断电连接摄像头排线，检查接触面和供电。
2. 用 HDMI 连接显示器，用下载器连接板卡。
3. 按本分支 README 选择 bit 文件，用 TD 的 BitWriter 下载到 SRAM。SRAM 是临时配置，断电后失效；Flash 配置会在下次上电加载。
4. 松开所有按键后按 KEY1 复位，先确认原图能连续显示，再调整图像和功能模式。

## 开关与按键

表中开关按电平写为 0 和 1。既有板上记录的方向是上 = 0、下 = 1；首次使用仍应核对底栏与板卡修订。KEY1 为复位键。

SW1、SW2 选择显示页：00 原图，01 目标高亮，10 灰度，11 颜色二值图。SW3、SW4 选择操作模式：

| SW3 SW4 | 用途 | KEY2 短按 | KEY3 短按 | KEY4 短按 |
|---|---|---|---|---|
| 00 | 日常观察 | 循环亮度档位 | 循环放大倍率 | 切换配色 |
| 01 | 矩形编辑 | 记录角点，第二点自动保存 | 清空未保存草稿 | 撤销末点；无草稿时逆序删区 |
| 10 | 实时顺序检查 | 开始或重测 | 暂停或继续 | 将本次 FAIL 报警静音 |
| 11 | 预留 | 无 | 无 | 无 |

KEY1 复位。短按在松手后确认；长按约 1 秒。KEY2 长按显隐视频标注，KEY3 长按启停跟踪。底栏状态始终显示。

在 00 普通页，KEY2+KEY4 长按进入校准，KEY3+KEY4 长按切换 0°/180°。先停止跟踪再校准；组合键全部松开后再进行下一次操作。

亮度档位为 16、32、48、64、80、90、105，默认 90；倍率为 1、1.5、2、3、4 倍。配色为红 A / 蓝 B 与黄 A / 紫 B，A 靠近尖端，B 在后方。调整亮度会停止跟踪，完成后需要重新校准并开启跟踪。

## 校准与工具选取

固定相机、照明、工作背景和工具上的色标。A 位于尖端一侧，B 位于后方。先选配色，再停止跟踪，进入校准。

依次采集白纸、空背景、A 色、B 色。每步摆稳后短按 KEY3，等待八个完整帧的采样与计算结束，再进行下一步。空背景步骤应移走色标，保留实际工作背景；材料取样应保留实际安装方式和衬底。KEY2 取消本次校准。失败或取消不会发布半套参数。

两组配色分别保存校准模型。更换材料、背景或光照，或调整相机亮度后，需要重新校准。复位或断电会清除校准。完成后，把两色中点移到中央引导区，再开启跟踪，等待连续三帧确认。

单色框或双框只表示检测到候选区域。尖端和跟随还需要满足配对与连续确认条件。遮挡后先观察底栏；长时间失去工具时，停止跟踪并回中央重新选取。

## 矩形区域与顺序检查

1. 完成校准并开启跟踪，让尖端准心有效。切换到 01。
2. 将准心放到 A 区第一个角，按下并松开 KEY2；再选择对角点。第二次松手后自动检查并保存。
3. 依次建立 B、C、D，最多四区。区域不能相接、重叠或包含，宽和高的坐标差都至少为 6 个原图像素。保存失败时按 KEY4 撤销末点后重选。
4. 切换到 10，将准心移到所有区域外，短按 KEY2。等待 WAIT OUT 结束，再按 A、B、C、D 的顺序进入。
5. 每次进出需连续三个有效新帧确认。提前进入后续区域，或离开后重入已完成区域，会显示 FAIL，并给出 EXP 应到区与 GOT 实际区。KEY4 只关闭本轮声音；KEY2 开始重测。

KEY3 可暂停实时顺序检查。恢复时先回到所有区域外，再等待确认。全部目标完成后显示 PASS。复位或断电会清除区域；移动相机或工作材料后应重新建区。SW5 是蜂鸣器物理开关。

T 表示当前区域内的连续停留时间，在区域内部移动也会计时。系统没有启用靠近、远离或静止分析。

## 底栏与异常

| 显示 | 含义或处理方法 |
|---|---|
| BRT / BUSY | 相机增益档位或配置忙，等待操作结束 |
| MARK ON / OFF | 视频准心、框线和标签的显隐状态 |
| NEXT / IN / T | 下一目标区、当前区域、连续区内停留时间，仅区域版本提供 |
| WAIT OUT | 先离开全部区域，再等待连续新帧确认 |
| INPUT LOST / STALE 250MS | 区域操作所需输入失效或超过 250 毫秒没有匹配的新图像 |
| F / V | 图像帧编号与校准参数版本 |
| LAT / AGE | 板内图像关联延迟或帧龄字段，具体页面随版本不同 |

LAT 不包含相机曝光与显示器响应，不能作为完整端到端时延。数字放大只放大已有像素，不增加采集细节。发生花屏、黑闪或停帧时，保留 bit 校验值、最后操作、完整底栏照片和连续视频，再按本分支的问题记录排查。

材料条件、实现细节和本版专项验证见 [详细说明](区域顺序_第一阶段_操作与实测.md)。
