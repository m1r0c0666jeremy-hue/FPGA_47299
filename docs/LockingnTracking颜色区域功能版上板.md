# 颜色区域功能版上板

本版采用判色和框选链路：相对色差与简化色相分类、粗网格寻找、局部8邻接区域分离、连续三帧确认。用于静止和缓慢移动的颜色区域；每色最多两个框。此版本没有工具唯一选择、估算尖端或自动移动放大窗口。

## 下载哪个文件

- BitWriter 添加 **`D:/aaa_FPGA/criticalwork/build/target_color_regions/target_color_regions.bit`**。
- TD 工程为 `D:/aaa_FPGA/criticalwork/td_project/target_color_regions.al`。`.al` 是工程入口，不能当作烧录文件。
- 最终是否已交付、bit哈希、源码与时序，以 `reports/color_regions_delivery.json` 为准。该清单生成前，构建仍在进行，不使用尝试目录或旧诊断 bit 代替。
- 推荐先下载到 SRAM（断电后不保留）进行本轮验证，确认效果后再决定是否烧 Flash。当前未替用户下载或烧写。

## 操作

1. KEY1复位后处于待命。SW3上=0选红A/蓝B，下=1选黄A/紫B。先核对底栏配色。
2. KEY3短按后松手启动/停止检测。KEY3长按1秒切换框、颜色标签和高亮页采样框显隐；隐藏时仍在检测，底栏保留。
3. SW1/SW2逻辑值对应：00原图、01色彩高亮、10灰度、11色彩二值。底栏必须随页面显示正确名称。高亮/二值由新的判色器产生，原图不经过模糊处理。
4. KEY4手动切换1/2/4倍，方向由SW4决定；显示窗口固定在源图中心。KEY2沿用SW4控制调亮/调暗，亮度控制可能改变摄像头采集值。
5. 高亮页中心绿色8×8源像素框是取样范围，底栏RGB是AWB后64像素平均值。将色环内部对准该框后读数；平均值不能代替逐像素色域。

顶部没有大数字面板。区域只画两像素细框与小标签，例如"蓝色B1"。底栏版本为R1-01；精确源码身份查交付清单。

## 本轮测试

清晰对焦，固定相机、正常实验室照明，先使用真实色环与打印纸，避开明显高光。每项静止10秒，再缓慢平移：

| 测试 | 观察内容 |
|---|---|
| 单独红、蓝、黄、紫 | 对应模式中高亮/二值是否覆盖材料；确认后只出现该颜色的框 |
| 暗蓝、暗紫、较淡打印颜色 | 掩码覆盖程度、掉框、是否把灰黑工具/纸面错误高亮 |
| 同配色两色同时出现，尺寸不同 | 两色独立框不要求相同面积；细环不要求实心 |
| 远处加入同色文字/第二块颜色 | 分开的区域分别成框，不出现把全屏同色像素包在一起的大框 |
| 同范围内两个不接触色块 | 分成两个框；两个范围重叠不应重复计数 |
| 遮挡、移出、恢复 | 消失时清框，恢复后重新寻找与三帧确认，不沿用旧测量 |
| 原图/高亮/灰度/色彩二值及1/2/4倍 | 名称、框位置与缩放一致，图像没有新增闪屏、黑块、掉行 |
| 切配色、停止/重新开启、长按隐藏 | 清除旧确认历史；显隐不改变判色结果；没有旧尖端 |

手机色卡作为兼容测试另记，不能替代实体材料主验收。记录有效框覆盖、抖动、掉框、错误区域和视频异常；模板为 `reports/color_regions_hardware_record.csv`。软件和布局布线通过不能证明实物稳定识别。

## 状态含义及边界

- "搜索中"：没有已确认区域，或者结果尚未与显示图像匹配。
- "区域/多个区域"：有已确认颜色区域，**不表示已经认定唯一工具**。
- "2+"：局部细检存在超过两个合格区域；"更多区域待判"：全图粗检测还有其他聚集范围未进入本轮两个局部槽。
- "区域拥挤"：行程、标签、等价边或处理期限超限；拒绝受影响颜色的框，继续显示视频。
- "无新帧"：连续15个显示帧没有新的图像编号，隐藏旧框。

工程初值：最高通道至少24，通道色差至少8，相对色差至少3/16；红0～30或345～360度、黄45～75度、蓝195～255度、紫255～330度，左闭右开。尚未由实物样本标定，不保证所有印刷色/光照都覆盖。失败时先区分"材料没有命中"和"命中但没有独立框"，不能不断扩大所有门槛。

同色文字与标记实际连在一起时属于一个连通区域；三个以上同色物体不能保证真实工具进入两个槽。局部框截断时扩大范围重测；实际画面边缘允许目标进入/移出。首次寻找和确认会占用多帧，不能把显示关联最多落后一采集帧误读为首次识别只需一帧。
