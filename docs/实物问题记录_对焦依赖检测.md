## 二、机理分析：逐像素判色对高频内容敏感

检测判据是逐像素硬阈值：主色通道 ≥ `color_min`(80)、主色高出其它两通道 ≥ `color_diff`(32)、
主色 ≥ 其它两通道的 1.5 倍；再要求每色面积 64~20000 像素、**填充率 ≥ 30%**。
**离焦相当于低通滤波**，因此"离焦才能识别"指向以下成因：

| 编号 | 成因 | 对焦时 | 离焦时 |
|---|---|---|---|
| ① | **打印半色调网点 / 表面细纹理** | 标记在画面里约 80~90 像素、物理约 15 mm → 约 5 像素/mm；普通打印 150 lpi ≈ 5.9 点/mm → **约 1 网点/像素**，去马赛克后逐像素 RGB 抖动 → 大量像素不满足颜色判据 → 面积/填充率失败 | 一像素内平均多个网点 → 颜色变纯变稳 → 通过 |
| ② | 锐边去马赛克伪彩 | 只影响边缘薄环，**内部仍应通过** → 难以解释"整块失败" | 边缘变软 → 伪彩消失 |
| ③ | 表面高光/反光 | 中心出现白亮斑（RGB 接近相等，必然不满足判据）→ 填充率下降 | 高光摊开、峰值下降 |
| ④ | AWB 随画面内容漂移（较弱） | 细节增多导致白平衡略移、标记饱和度下降 | 画面更均匀 → 更稳 |

**倾向判断**：既然**整块标记**在对焦时都判不出来，主因更可能是 **①（或 ①+③）**，而不是只影响边缘的 ②；
不排除 ②/③ 同时存在。以上为推断，需由下面的自测确认。

## 三、未完成的自测（本次暂停继续测试，留待后续）

1. 把标记换成**哑光纯色不干胶/色卡**（不要打印件）→ 对焦下能否锁定：
   **能锁定 → ① 确认**（现场用不干胶即可，不必改 RTL）；仍不能 → ① 排除，指向 ②/③/④（必须改 RTL 低通）。

4. 对比对焦/离焦两幅画面的**背景亮度与白平衡** → 判断 ④ 是否参与。

## 四、建议（按性价比排序）

| 优先级 | 建议 | 说明 |
|---|---|---|
| ★★★ | **判色前加一次低通**：2×2 或 3×3 盒式平均后再走现有阈值（或 2×2 平均后降采样判色、坐标换算回原图）| 等价于"把离焦做的事搬进 RTL"，同时缓解 ①②③；行缓存已有，资源几乎为零 |
| ★★☆ | 阈值放宽并分级：`color_diff` 32→16、比值 1.5→1.25、`fill_percent_min` 30%→15%，并加 3×3 多数表决补洞 | 与低通配合使用 |
| ★★☆ | 弱化绝对亮度门限 `color_min`，改用**通道相对差**判色 | 抗高光 |
| ★★★ (物理) | 标记用**哑光纯色不干胶**、避免反光、面积留 3~5 倍余量（`area_min`=64 很容易被削弱）| 现场立即可做，零代码 |
| ★☆☆ | 明确**窗口跟随对象**（标记中心 or 估算尖端）并写进文档；若跟随尖端，建议改为"框中心优先" | 避免把标记甩出观察窗 |

## 五、结论与边界

- **本记录确认一件事**：在中间 bit 上，检测/跟踪/窗口/OSD 链路在实物上是**活的**，但**明显依赖离焦**；
- **不确认**：锁定精度、失锁/恢复、倾斜边界、三倍率×四模式一致性（均未测）；也**不代表**接入阻塞已解决或 bit 已同源；
- 与接入阻塞（帧头 FIFO 复位丢数据）是**两个独立问题**，不要混为一谈；
- 后续：由队友按第四节做 RTL 侧低通/阈值调整并**重新同源构建**后，再按
  [验证报告](../reports/LockingnTracking验证报告.md) 的实物步骤做完整验收。
