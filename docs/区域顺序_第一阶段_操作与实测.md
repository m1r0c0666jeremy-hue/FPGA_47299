# 矩形区域示教与顺序报警：操作与实测

本版仅支持与原图横纵轴平行的矩形，保留4区A-D；任意多边形、精确距离和接近/远离显示暂缓。

当前源码107项软件、最终零冲突DRC与建立+0.005ns/保持+0.020ns均通过，实物尚待验收。只有交付目录中同时具有delivery.json、SHA256SUMS.txt、bit及同源ZIP，且delivery状态通过，才是待上板候选。不要烧录失败布局目录中的产物。

## 开关与按键

SW1、SW2继续选择原四种图像模式。SW3、SW4作为一对模式开关，以下按电平顺序SW3、SW4写为00/01/10/11；首次上板核对实物拨动方向：00显示原概况，01显示EDIT，10显示IDLE/WAIT OUT/RUN等测试状态，11显示ROUTE RESERVED。SW5为蜂鸣器物理开关。

|SW3/SW4|用途|KEY2短按|KEY3短按|KEY4短按|
|---|---|---|---|---|
|00|日常观察|亮度循环|倍率循环|红蓝/黄紫配色|
|01|EDIT编辑区域|记录准心所在点|检查并保存矩形|撤销草稿末点；无草稿时删除最后保存区|
|10|TEST顺序测试|开始或重新测试|暂停/继续|关闭本轮失败报警声音|
|11|ROUTE RESERVED|预留|预留|预留|

长按KEY2约1秒控制信息显隐；长按KEY3约1秒开关跟踪。长按不同时触发短按。00模式下，KEY2+KEY4长按进入校准，KEY3+KEY4长按切换图像方向；组合键须全松开后再操作。校准期间KEY3采样、KEY2取消，按原四步流程进行。

亮度顺序为16→32→48→64→80→90→105→16，默认90。倍率顺序为1→1.5→2→3→4→1，默认保留原180°方向。BRIGHTNESS BUSY期间等待相机完成；BRT FAILED. CHECK CAM表示检查相机，不把未完成请求当作亮度已应用。

## 从建区到重测

1. 固定相机和工作材料，完成原有配色、校准与跟踪，让真实工具尖端的十字准心稳定有效。本阶段区域记录在原图坐标中；移动相机或材料后应重新建区。
2. 切01。移动准心到A区第一个顶点，按下并松开KEY2。记录的是按下时的位置；松手后的轻微位移不改变该点。长按、组合键或位置失效会取消此次记点。
3. 只记录两个对角点，最后短按KEY3保存。角点可以按任意对角顺序记录，系统自动整理边界；宽、高坐标差均至少6个原图像素，为2像素防抖带保留内部空间。与已有区相接、重叠、包含，或矩形太小，都会拒绝保存并保留草稿，按KEY4撤回末点后修正。
4. 按相同方式依次建B、C、D，最多4区。AREA A～D表明顺序。草稿可跨模式保留，但未保存的草稿会阻止开始测试。删除按保存顺序逆序进行，不会留下顺序编号空洞。
5. 切10，准心先移到所有区域外，再短按KEY2。WAIT OUT期间等待至少3个有效新画面确认在区外。RUN后按A→B→C→D进入，当前目标黄色，已完成绿色，其余灰色。每次进入/离开需连续3个有效新帧确认；矩形边界内外2个原图像素的矩形防抖带内暂不改变进出状态。
6. 提前进入后续区域，或离开后重新进入已完成区域，会显示FAIL及EXP应到区/GOT实际区，并间歇鸣叫；持续停留在刚完成区不重复触发。KEY4只静音本轮，结果保留。KEY2重新测试时从A开始并恢复报警能力。最后一个区域完成后PASS锁定。
7. KEY3暂停并保留进度；继续前先回到全部区域外，重新确认3个新帧后接续。运行时KEY2不直接清进度。离开测试模式或改变配置会使本轮作废，区域保留；恢复测试需重新开始。复位或断电清空区域。

跟踪关闭、准心/视频无效或250毫秒没有有效新源帧时显示INPUT LOST，中断本轮；这种中断不当作乱序鸣叫。重复显示旧画面不会推进顺序。信息隐藏后仍执行判断，保留FAIL、PAUSED、INPUT LOST、WAIT OUT等必要提示。

## 英文信息对照

|显示|含义|
|---|---|
|PTS 2/2、SAVE 2/4|草稿2个角点/最多2点，已保存2区/最多4区|
|TIP READY / TIP NOT READY|准心有效/尚不可记点|
|SET TWO CORNERS / MAX 2 CORNERS / MAX 4 AREAS|需要两个对角点/角点或区域数量达到上限|
|RECT TOO SMALL / AREA TOUCH/OVER|矩形过小/与已有区域相接、重叠或包含|
|FINISH DRAFT / NO SAVED AREAS|先保存或撤销草稿/没有保存区域|
|WAIT OUT / LEAVE ALL AREAS|开始或恢复前先离开全部区域|
|NEXT B / IN A|下一应进入B/当前确认在A|
|T002.5s|本次连续停留2.5秒，精度0.1秒，上限999.9秒；离开保留，再次进入重新计时|
|EXP B GOT C / MUTE|应到B却进入C/本轮声音已关闭|
|BUSY / INPUT LOST|几何或显示准备中/有效新图像中断|
|LAT、AGE、F、V|保留原板内延迟、帧龄、帧编号及模型版本信息|
