# 矩形区域示教与顺序报警：操作与实测

> 2026-10-26：当前分支正在实施30秒/20Hz阶梯轨迹示教、共享顺序计时及简化距离运动状态，见[新增操作说明](示教录制回放与运动状态_操作与验证.md)。下文为10月25日矩形候选的历史操作与待测表，11预留和趋势暂缓不适用于本轮新功能；新交付尚待全部验证。

本版仅支持与原图横纵轴平行的矩形，保留4区A-D；任意多边形、精确距离和接近/远离显示暂缓。

本轮为2026-10-25跨帧记点与自动保存修订，111项当前软件回归和新的整机物理已通过：最终布线零冲突、无异常时序路径，建立+0.101ns、保持+0.020ns。bit SHA256为 `15de0fc76aca57e53bf20ab97853f63be6647577e82f51ee52afe645089a8d72`。实物仍待Jeremy验收。2026-10-24的107项与bit仅属于历史候选；只使用具有delivery.json、SHA256SUMS.txt、bit及同源ZIP并经独立校验的新交付目录。

## 开关与按键

SW1、SW2继续选择原四种图像模式。SW3、SW4作为一对模式开关，以下按电平顺序SW3、SW4写为00/01/10/11；首次上板核对实物拨动方向：00显示原概况，01显示EDIT，10显示IDLE/WAIT OUT/RUN等测试状态，11显示ROUTE RESERVED。SW5为蜂鸣器物理开关。

|SW3/SW4|用途|KEY2短按|KEY3短按|KEY4短按|
|---|---|---|---|---|
|00|日常观察|亮度循环|倍率循环|红蓝/黄紫配色|
|01|EDIT编辑区域|记录准心所在点，第二点自动检查保存|清空未保存草稿|撤销草稿末点；无草稿时删除最后保存区|
|10|TEST顺序测试|开始或重新测试|暂停/继续|关闭本轮失败报警声音|
|11|ROUTE RESERVED|预留|预留|预留|

长按KEY2约1秒只控制视频准心、检测框、工具标签和区域线条显隐；底部两行文字始终显示。长按KEY3约1秒开关跟踪。长按不同时触发短按。00模式下，KEY2+KEY4长按进入校准，KEY3+KEY4长按切换图像方向；组合键须全松开后再操作。校准期间KEY3采样、KEY2取消，按原四步流程进行。

亮度顺序为16→32→48→64→80→90→105→16，默认90。调整亮度会停止跟踪，完成后需长按KEY3重新开启；如提示RECALIBRATE，按原校准流程处理。倍率顺序为1→1.5→2→3→4→1，默认保留原180°方向。BRIGHTNESS BUSY期间等待相机完成；BRT FAILED. CHECK CAM表示检查相机，不把未完成请求当作亮度已应用。

新修订画面的判据：00底栏有明确ZOOM、三位BRT亮度数值和MARK ON/OFF；01有AUTO SAVE。仍须核对BitWriter实际download路径及交付SHA256，不能只凭打开的工程标题判断bit版本。

## 从建区到重测

1. 固定相机和工作材料，完成原有配色、校准与跟踪，让真实工具尖端的十字准心稳定有效。本阶段区域记录在原图坐标中；移动相机或材料后应重新建区。
2. 切01。移动准心到A区第一个顶点，按下并松开KEY2。记录的是消抖确认按下时的位置；松手后的轻微位移不改变该点。长按、组合键或真实位置失效会取消此次记点，正常换帧消隐不会取消。取消原因保留至下一次编辑动作；恢复后需重新按键。
3. 只记录两个对角点，第二次KEY2短按松手后自动检查并保存，不需要KEY3确认。KEY3短按只清空未保存草稿，不删除已保存区。角点可以按任意对角顺序记录，系统自动整理边界；宽、高坐标差均至少6个原图像素。与已有区相接、重叠、包含，或矩形太小，都会拒绝保存并保留草稿，按KEY4撤回末点后修正。
4. 按相同方式依次建B、C、D，最多4区。AREA A～D表明顺序。草稿可跨模式保留，但未保存的草稿会阻止开始测试。删除按保存顺序逆序进行，不会留下顺序编号空洞。
5. 切10，准心先移到所有区域外，再短按KEY2。WAIT OUT期间等待至少3个有效新画面确认在区外。RUN后按A→B→C→D进入，当前目标黄色，已完成绿色，其余灰色。每次进入/离开需连续3个有效新帧确认；矩形边界内外2个原图像素的矩形防抖带内暂不改变进出状态。
6. 提前进入后续区域，或离开后重新进入已完成区域，会显示FAIL及EXP应到区/GOT实际区，并间歇鸣叫；持续停留在刚完成区不重复触发。KEY4只静音本轮，结果保留。KEY2重新测试时从A开始并恢复报警能力。最后一个区域完成后PASS锁定。
7. KEY3暂停并保留进度；继续前先回到全部区域外，重新确认3个新帧后接续。运行时KEY2不直接清进度。离开测试模式或改变配置会使本轮作废，区域保留；恢复测试需重新开始。复位或断电清空区域。

跟踪关闭、准心/视频无效或250毫秒没有有效新源帧时显示INPUT LOST，中断本轮；这种中断不当作乱序鸣叫。重复显示旧画面不会推进顺序。视频标注隐藏后仍执行判断，两行底栏及FAIL、PAUSED、INPUT LOST、WAIT OUT等提示保持可见。
