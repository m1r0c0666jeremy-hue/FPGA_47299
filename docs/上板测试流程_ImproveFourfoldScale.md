# ImproveFourfoldScale 上板测试流程（4 倍双线性 A/B 对照）

对象：`build/improve_fourfold_scale/improve_fourfold_scale.bit`
（SHA256 `979e1c92de9ca899f3cd798abbd5fcba51746dd2fd2a4aa33366618ec1c1f393`）。
对照：`build/scaling_test/scaling_test.bit`（已验收，`a598cff3…`）。
本版**只把 4 倍的「原图 / 灰度」改为双线性**；1/2 倍与边缘/二值化保持最近邻（RTL 上旁路插值），
按键、开关、增益、准心、OSD 全部不变。逐条要求见 [使用与实现](ImproveFourfoldScale使用与实现.md)。

## 一、固定拍摄条件（A/B 的前提）

- 相机/镜头/**拍摄距离**固定；目标固定：笔记本全屏显示 `四倍缩放AB对照卡_1920x1080.png`（亮度、角度不变）；
- **照明固定**；**增益固定**（KEY1 复位后不要按 KEY2）；**选点固定**（两次都用 `(0640,0360)` 或同一 OSD 读数）；
- 只 `PROGRAM_SRAM`、不烧 Flash；先拍旧 bit 再换新 bit，中途不动机位与目标。

## 二、步骤

1. **旧 bit 基线**：下载 → KEY1 → 依次拍 1× 原图、2× 原图、4× 原图、4× 灰度、4× 边缘、4× 二值化；
2. **新 bit**：重新下载 → KEY1 → 恢复同一选点/倍率/增益 → 拍同样 6 张；
3. **逐项判读**（判据见下表）；
4. **功能回归**：四模式×三倍率、KEY3 四向移动与加速/锁定/冲突/边界、KEY4 倍率切换、KEY2 增益（移动不应改变亮度）；
5. **动态与稳定性**：移动目标、观察窗到四角、反复切倍率/模式/复位，记录错位、闪烁、黑屏、拖影、行尾黑线；
6. 结论写入验证报告；失焦或镜头分辨率不足须与插值问题分开记录。

## 三、判读表

| 检查项 | 通过 | 异常 |
|---|---|---|
| 1× 全部模式 / 2× 全部模式 | 与旧 bit 无可辨差异 | 有可见差异 |
| 4× 边缘 / 二值化 | 与旧 bit 无可辨差异（旁路插值）| 有差异 |
| 4× 原图/灰度的方块过渡 | **明显减弱**（过渡宽度变宽）| 无变化 = 插值未生效 |
| 4× 1px/2px 细线与窄缝 | **仍能分辨出线/缝**（缝底仍达深谷）| 消失或糊合 = 可辨性下降 |
| 斜边/圆/细网格 | 锯齿减少 | 出现振铃/过冲（算法不允许）|
| 准心尺寸/落点、OSD、坐标、倍率 | 与旧 bit 一致 | 位置或文字变化 |
| 四角标记 | 两种 bit 位置相同 | 位移/裁剪差异 |

## 四、量化方法（本轮实际采用）

- 取照片中"最强对比行"的均值剖面；
- **边缘过渡宽度** = 10%→90% 跨越像素数（旧 17 → 新 25 像素，平滑生效）；
- **窄缝深度** = 缝底相对满对比的比例（旧 0.71 → 新 0.71，可辨性未下降）。

## 五、范围外

锐化/超分/AI 补图/多帧融合/跟踪未实现；1×/2× 仍为最近邻；旧打包复位、采集坏帧隔离、DDR 无响应自恢复仍未解决；
30 分钟连续运行不作为前置条件。
