# Final_Mode_1101 配色与帧率演示版

默认红 A、黄 B，备用蓝 A、紫 B。A 靠近尖端，B 在后方。在 00 模式短按 KEY4 切组，两组分别执行白纸、空背景、A、B 四步校准。

本版本保留 K 调节、七档增益、五档放大、四矩形和约 30 秒路线示教。FPS 统计每秒首次显示的有效完整源图像数量，重复画面、HDMI 重复刷新和示教点不计入。

下载文件为 [target_color_regions.bit](../releases/Final_Mode_1101/target_color_regions.bit)。操作见 [使用手册](USER_GUIDE.md)，校验值与工程入口见 [编译与下载](BUILD.md)。

旧 DDR 配置风险保留，花屏根因与长期稳定性仍待实物确认。软件与最终物理检查通过不替代板上验收。
