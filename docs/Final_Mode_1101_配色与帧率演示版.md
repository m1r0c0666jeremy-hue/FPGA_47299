# Final_Mode_1101 配色与帧率演示版

以已上板的旧版4081ad0为基线，只加入红黄／蓝紫配色和有效图像FPS。
当前为开发中，最终物理检查通过前没有本版合格烧录文件。

默认红A在前、黄B在后，备用蓝A在前、紫B在后；00短按KEY4切组。
两组保留独立四步校准。请重新校准当前材料，K公式和调节操作保持。
K与亮度、四显示页、五档数字倍率、两种方向、四矩形和30秒示教全部保留。
摄像头、DDR、检测算法、读图、视口、时钟和约束恢复旧版；
本版没有原生高清2倍、诊断遥测或显示分拍优化。

FPS是每秒首次显示的有效完整源图像身份数，按帧号和采集代次去重。
重复旧帧、示教虚拟点和HDMI重复刷新不增加FPS；
关闭跟踪、移走工具不应停止正常图像计数，停帧后下一统计窗口归零。
显示复用旧AGE的数值转换通道，没有新增数值除法器。
普通／编辑／测试的FPS位于第二行原AGE位置；
校准时位于第一行调试编号区；示教按顺序启用状态使用空白位置。
保留原按键、下一目标、区内停留、SEQ OFF、校准帮助及错误文字。

旧版原有底栏显示资格和其他行为保持，没有把额外的防闪字修复混进来。
旧DDR实际50MHz参考与IP名义100MHz不匹配的已知风险仍保留，
花屏根因没有确诊，本演示版不能宣称长期稳定性已经解决。
软件和最终物理通过只能标为候选，实物仍由Jeremy确认。

验收：核对交付SHA256；红黄重新校准，切备用组；检查K、亮度、五倍率、
四矩形与示教；确认FPS在跟踪关闭和移走工具后仍正常，停帧后归零。
遇到严重花屏应记录最后操作、视频和底栏状态，不能判为稳定性通过。
