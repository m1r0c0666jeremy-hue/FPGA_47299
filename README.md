# 双色工具定位与跟踪实验

通过前红后蓝两个色标估算工具尖端，并让放大窗口随工具移动。本分支保存早期联调版本，采集接入存在帧头丢数据问题，没有可推荐下载的完整交付。

当前分支：`docs/locking-tracking-focus-issue`。这是历史文档分支。首次使用完整作品请切换到 [main](https://github.com/m1r0c0666jeremy-hue/FPGA_47299/tree/main)。

## 快速开始

1. 准备 HX1P35A 开发板、SC500CS 摄像头、HDMI 显示器和下载器。
2. 在 TD 6.2.168116 中打开 [td_project/target_lock.al](td_project/target_lock.al)，或直接下载下表的 bit。
3. 先通过 BitWriter 下载到 SRAM，复位后确认原图，再按使用手册校准和操作。

| 文件 | 路径 |
|---|---|
| TD 工程 | [td_project/target_lock.al](td_project/target_lock.al) |
| 下载文件 | 见 [构建与交付说明](docs/BUILD.md)，本分支未附可直接推荐的最终 bit |
| 操作手册 | [连接、校准、开关与按键](docs/USER_GUIDE.md) |

## 操作速查

| 输入 | 功能 |
|---|---|
| SW1 SW2 = 00 / 01 / 10 / 11 | 原图 / 边缘 / 灰度 / 二值化 |
| KEY1 | 复位至待命 |
| KEY2，SW3 = 1 / 0 | 调亮 / 调暗 |
| KEY3 | 启动搜索和跟踪，再按停止 |
| KEY4，SW4 = 1 / 0 | 放大 / 缩小，档位 1、2、4 倍 |
| SW3 = 1 / 0 | 显示 / 隐藏视频标注 |

此版本只使用红 A、蓝 B。KEY3 长按不会反复启停。帧头采集问题尚未在此分支修复，请以实验代码阅读为主。
