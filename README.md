## 当前限制

厂家例程存在打包模块忽略复位、写缓存满时仍写、读缓存空时仍读等问题，针对性测试已复现。正常输入条件下的逻辑测试通过，不代表异常恢复通过。完整帧有效性、跨时钟复位释放、MIPI/DDR物理接口和持续运行仍待验证；详见验证报告。

不应单独拷贝 `.al`：迁移时携带整个 `criticalwork` 目录。重新编译不需要原下载目录，也不需要重新运行一次性导入脚本。
