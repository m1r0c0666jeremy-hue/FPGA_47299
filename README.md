# 原生 1080p30 视觉辅助候选工程

使用 SC500CS 原生 1920×1080 采集、颜色识别、DDR 缓存和 HDMI 1080p30 输出。支持两组配色、五档放大、四步校准和跟随，实物效果仍待验收。

当前分支：`native-1080p`。这是独立功能或历史实验分支。完整的区域与路线操作见 [main](https://github.com/m1r0c0666jeremy-hue/FPGA_47299/tree/main)。

## 快速开始

1. 准备 HX1P35A 开发板、SC500CS 摄像头、HDMI 显示器和下载器。
2. 在 TD 6.2.168116 中打开 [td_project/target_color_regions_1080p30.al](td_project/target_color_regions_1080p30.al)，或直接下载下表的 bit。
3. 先通过 BitWriter 下载到 SRAM，复位后确认原图，再按使用手册校准和操作。

## 操作速查

| 输入 | 功能 |
|---|---|
| SW1 SW2 = 00 / 01 / 10 / 11 | 原图 / 目标高亮 / 灰度 / 二值图 |
| SW3 = 0 / 1 | 红 A、蓝 B / 黄 A、紫 B |
| SW4 = 1 / 0 | 增加 / 减少增益或倍率 |
| KEY1 | 复位 |
| KEY2 | 按 SW4 调节相机增益；校准中取消 |
| KEY3 短按松手 | 启停检测；支持校准的版本中确认取样 |
| KEY3 长按约 1 秒 | 显隐视频标注，底栏保留 |
| KEY4 | 按 SW4 切换 1、1.5、2、3、4 倍，到端点保持 |
| KEY2+KEY4 长按约 1 秒 | 停止跟踪后进入四步校准 |
| KEY3+KEY4 长按约 1 秒 | 切换 0°/180°，默认 180° |
