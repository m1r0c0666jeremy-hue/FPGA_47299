# 矩形区域示教与顺序检查

用工具尖端设定最多四个矩形区域，再按 A、B、C、D 顺序移动。系统显示当前区域、停留时间和顺序结果，错序时可鸣叫报警。

当前分支：`Behaviour_region_1024`。这是独立功能或历史实验分支。完整的区域与路线操作见 [main](https://github.com/m1r0c0666jeremy-hue/FPGA_47299/tree/main)。

## 快速开始

1. 准备 HX1P35A 开发板、SC500CS 摄像头、HDMI 显示器和下载器。
2. 在 TD 6.2.168116 中打开 [td_project/target_color_regions_stage1.al](td_project/target_color_regions_stage1.al)，或直接下载下表的 bit。
3. 先通过 BitWriter 下载到 SRAM，复位后确认原图，再按使用手册校准和操作。

## 操作速查

| SW3 SW4 | 用途 | KEY2 短按 | KEY3 短按 | KEY4 短按 |
|---|---|---|---|---|
| 00 | 日常观察 | 循环亮度档位 | 循环放大倍率 | 切换配色 |
| 01 | 矩形编辑 | 记录角点，第二点自动保存 | 清空未保存草稿 | 撤销末点；无草稿时逆序删区 |
| 10 | 实时顺序检查 | 开始或重测 | 暂停或继续 | 将本次 FAIL 报警静音 |
| 11 | 预留 | 无 | 无 | 无 |

KEY1 复位。短按在松手后确认；长按约 1 秒。KEY2 长按显隐视频标注，KEY3 长按启停跟踪。底栏状态始终显示。

在 00 普通页，KEY2+KEY4 长按进入校准，KEY3+KEY4 长按切换 0°/180°。先停止跟踪再校准；组合键全部松开后再进行下一次操作。

亮度档位为 16、32、48、64、80、90、105，默认 90；倍率为 1、1.5、2、3、4 倍。配色为红 A / 蓝 B 与黄 A / 紫 B，A 靠近尖端，B 在后方。调整亮度会停止跟踪，完成后需要重新校准并开启跟踪。

SW1、SW2 选择图像页：00 原图、01 目标高亮、10 灰度、11 颜色二值图。SW5 为蜂鸣器物理开关。
