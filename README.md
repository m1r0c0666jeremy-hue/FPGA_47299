输出有效区为 1280×720，总时序 1650×750，保留例程 75 MHz 像素时钟，理论刷新率 **60.606 Hz**。不能称为已经验证的标准 60 Hz。显示器可否接收这一模式、等比例放大到1080p且不裁边，需实测。

## 当前限制

队友增加了写满/读空门控，但完整帧有效性与丢数据恢复尚未完成。打包复位补丁改在未参与综合的同名源码；读出empty门控还有有效尾字丢失问题。普通出图成功与异常恢复、跨时钟复位释放、30分钟持续稳定性分别验收，详见最新复核报告。历史验证报告按其对应提交解释。

不应单独拷贝 `.al`：迁移时携带整个 `criticalwork` 目录。重新编译不需要原下载目录，也不需要重新运行一次性导入脚本。
