# 基于 FPGA 的精密操作视觉辅助系统

通过摄像头、FPGA 图像处理和 HDMI 显示，为工具尖端定位、局部放大观察和操作区域顺序检查提供视觉辅助。支持双色标记校准、K 值调节、四个矩形区域，以及最长约 30 秒的路线录制与回放。

当前分支：`main`。主干使用远端 Final_Mode_1028 的已交付工程；保留原 main 与其他分支的 Git 历史。

## 快速开始

1. 准备 HX1P35A 开发板、SC500CS 摄像头、HDMI 显示器和下载器。
2. 在 TD 6.2.168116 中打开 [td_project/target_color_regions_stage1.al](td_project/target_color_regions_stage1.al)，或直接下载下表的 bit。
3. 先通过 BitWriter 下载到 SRAM，复位后确认原图，再按使用手册校准和操作。

## 操作速查

| SW3 SW4 | 用途 | KEY2 短按 | KEY3 短按 | KEY4 短按 |
|---|---|---|---|---|
| 00 | 日常观察 | 循环亮度档位 | 循环放大倍率 | 切换配色 |
| 01 | 矩形编辑 | 记录角点，第二点自动保存 | 无动作 | 撤销末点；无草稿时逆序删区 |
| 10 | 实时顺序检查 | 开始或重测 | 暂停或继续 | 将本次 FAIL 报警静音 |
| 11 | 路线示教 | 开始或结束录制 | 播放或从头重播 | 停止回放、消音并返回实时准心 |

KEY1 复位。短按在松手后确认；长按约 1 秒。KEY2 长按显隐视频标注，KEY3 长按启停跟踪。底栏状态始终显示。

在 00 普通页，KEY2+KEY4 长按进入校准，KEY3+KEY4 长按切换 0°/180°。先停止跟踪再校准；组合键全部松开后再进行下一次操作。

亮度档位为 16、32、48、64、80、90、105，默认 90；倍率为 1、1.5、2、3、4 倍。配色为红 A / 蓝 B 与黄 A / 紫 B，A 靠近尖端，B 在后方。调整亮度会停止跟踪，完成后需要重新校准并开启跟踪。

00 普通页长按 KEY2+KEY3 进入 K 调节页。页内 KEY3 短按加 0.01，KEY4 短按减 0.01，KEY2 短按退出。K 范围 0.00～2.00，默认 0.50，复位恢复默认。K 页保留标注和跟踪长按，禁用校准与方向组合键。

11 模式长按 KEY4 清除路线。回放没有暂停功能；需要从头播放时先按 KEY4 停止，再按 KEY3。
播放中再短按 KEY3 会被忽略。

SW1、SW2 选择图像页：00 原图、01 目标高亮、10 灰度、11 颜色二值图。SW5 为蜂鸣器物理开关。

## 使用边界

工具由操作员移动，系统提供位置与顺序反馈。路线回放使用记录坐标，不表示实时实物移动，也不检测夹取质量或焊接质量。

本版本沿用旧 DDR 配置，50MHz 实际参考与 IP 名义 100MHz 存在已知不匹配风险，花屏根因与长期稳定性仍需实物确认。

来源见 [源码与素材说明](docs/来源与修改记录.md)。厂家 IP、字体和参考工程保留原有声明。本仓库暂未添加统一开源许可证。
